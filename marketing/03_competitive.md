## 주요 경쟁사

### 카택스 비즈 (주요 경쟁자)

[확인] 카택스도 기본 기능은 무제한 무료입니다. 무료 정책이 차별점이 될 수 없습니다.

| 항목 | 카택스 비즈 | DriveLog |
|------|------------|----------|
| 무료 플랜 | 차량 100대까지 운행기록/일지 생성 무제한 무료 | 운전자 1인 운행기록 무제한 무료 |
| 무료체험 | 프리미엄 2주 무료체험 | 없음 (처음부터 무료) |
| 유료 플랜 가격 | Plus 월 5,000원/차량, Premium 월 9,000원/차량 | 미정 |
| 데이터 위치 | 카택스 클라우드 | 폰 로컬 (무료) / Google Drive (유료 예정) |
| 보고서 기준 | [확인 필요] | 무료: 운전자 기준, 유료: 차량 기준 |
| 다중 운전자 | [확인 필요] | 유료 플랜 |
| 플랫폼 | iOS + Android | Android (현재) |
| 회사 규모 | 8년 흑자 지속 중인 검증된 사업 | 초기 |

**카택스 사용자 주요 불만 (앱스토어 리뷰 기반)**
- GPS 기반이라 수동 조작 필요 (자동 감지 부족)
- 요금제 개선 요청
- 맞춤 기능 부족

**카택스 대비 DriveLog 실제 강점 (재정의)**
- ~~무료 무제한~~ → 카택스도 무료 있음, 차별점 아님
- **데이터 소유권:** Google Drive에 사용자 소유로 저장 (카택스는 카택스 서버에 보관)
- **락인 없음:** 서비스 종료 시에도 데이터 안전 (카택스 서비스 종료 시 데이터 소멸 위험)
- **블루투스 자동 트리거:** 수동 조작 없이 자동 운행 감지 (카택스 불만 항목 직접 해결)

**카택스 대비 DriveLog 약점**
- iOS 미지원 [현재]
- 브랜드 인지도 없음
- 세무사 네트워크 없음
- 카택스는 8년 운영 → 안정성·신뢰도 격차

## 포지셔닝 재정의

카택스와 무료 정책이 비슷하다면, 차별화 메시지는 다음으로 전환:

> "내 데이터는 내 Google Drive에" — 데이터 소유권 + 서비스 독립성
> "켜면 자동으로" — 블루투스 자동 트리거 (카택스 불만 해결)
