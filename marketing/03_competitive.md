## 실제 차별점 (검증된 것만)

### 1. 데이터 암호화 + 소유권 [강력한 차별점]

카택스는 운행 데이터를 자사 서버에 보관합니다.
DriveLog는 AES-256-GCM으로 암호화한 후 **사용자 본인의 Google Drive**에 저장합니다.

- 서비스가 종료되어도 데이터는 사용자 Drive에 남음
- 라라캣소프트 서버에는 운행 내용이 저장되지 않음 (암호화키 없이는 복호화 불가)
- 법인세법상 5년 보관 의무도 사용자 Drive로 충족

**마케팅 메시지:** "운행기록은 암호화되어 내 Google Drive에만 저장됩니다"

### 2. 진입 장벽 제로 (로컬 모드) [개인사업자 차별점]

회원가입·회사 코드 없이 앱 설치 후 즉시 사용 가능합니다.
개인사업자·자영업자가 복잡한 설정 없이 바로 시작할 수 있습니다.

### 3. Windows 관리자 앱 [경리 담당자 차별점]

관리자 앱이 Windows를 지원합니다.
PC에서 업무 처리하는 경리 담당자가 별도 모바일 없이 관리 가능합니다.

### 4. 국세청 양식 완전 자동화 [공통 차별점]

- 상호명·사업자등록번호 자동 입력
- 업무/출퇴근/기타 목적별 컬럼 자동 분류 (⑧⑨항)
- 업무사용비율 자동 계산 (⑬항)

## 현재 약점 (솔직하게)

| 약점 | 현황 | 개선 방향 |
|------|------|----------|
| iOS 운전자 앱 미지원 | Android만 출시 | 추후 출시 예정 |
| 브랜드 인지도 없음 | 신규 서비스 | 세무사 채널로 신뢰 구축 |
| Drive 동기화 수동 | 관리자가 버튼 직접 클릭 필요 | 자동 폴링 구현 필요 |
| 수동 운행 기록 | 블루투스 자동 트리거 제거 | 자동화 재도입 검토 필요 |
