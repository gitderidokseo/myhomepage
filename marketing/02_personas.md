# 타겟 페르소나

최종 업데이트: 2026-05-19 (로컬 모드 페르소나 추가, 경리 담당자 업데이트)

## Persona A — 소규모 법인 대표 (핵심 타겟)

**프로필**
- 직원 5~20명 규모 법인 대표
- 업무용 차량 1~3대 보유
- 세무사에게 기장 위임 중
- 앱 사용에 익숙하나 복잡한 설정은 싫어함

**현재 행동**
- 운행기록부를 수기로 작성하거나 아예 안 쓰다가 세무조사 때 당황
- 또는 엑셀로 관리하다 누락 발생

**핵심 니즈**
- "신경 안 써도 자동으로 기록되는 것"
- "세무사가 바로 쓸 수 있는 양식으로 나오는 것"

**전환 트리거**
- 세무사가 추천했을 때
- 세무조사 받거나 주변에서 들었을 때
- 앱스토어 검색 ("운행기록부 앱")

**진입 경로**
- 관리자 앱 설치 → 회사 코드 발급 → 운전자(본인 또는 직원)에게 배포

---

## Persona B — 세무사 / 세무법인 직원 (채널 파트너)

**프로필**
- 법인 고객 30~100개 이상 보유
- 고객들의 운행기록부 미작성으로 매년 골머리
- 직접 툴을 추천해주면 고객 만족도 올라감

**핵심 니즈**
- "고객에게 추천했을 때 쉽게 쓸 수 있는 앱"
- "국세청 양식 그대로 나오는 것" — 상호명·사업자번호 자동 입력, 업무사용비율 자동 계산 [확인: 구현됨]
- "여러 고객사를 한눈에 볼 수 있는 관리 화면" [현재 미구현 — 향후 과제]

**전환 트리거**
- 세무사 커뮤니티/협회에서 추천 사례 공유
- 무료로 써보고 고객에게 권유

## Persona C — 다차량 법인 경리 담당 (고가치 유료 전환 타겟)

**프로필**
- 차량 5대 이상 보유 법인 경리/총무 담당
- 여러 운전자의 기록을 취합해서 차량별로 정리하는 게 매달 고역
- 현재 카택스 유료 사용 중이거나 엑셀로 수동 취합 중
- **PC(Windows)에서 업무 처리** — 관리자 앱이 Windows 지원 [확인: 구현됨]

**핵심 니즈**
- 운전자별 앱 → 차량별 취합 자동화
- PC에서 관리하고 Excel로 국세청 제출 (별도 IT 담당자 불필요)
- Google Drive 연동으로 데이터 안전 보관 + 암호화

**사용 흐름**
1. 경리 담당자: 관리자 앱(Windows) 설치 → Google Drive 연동 → 회사 코드 발급
2. 각 운전자: 운전자 앱(Android) 설치 → 회사 코드 입력 → 승인 후 사용
3. 경리 담당자: 월말 "Drive 동기화" 버튼 → 차량별 Excel 내보내기 → 국세청 제출

**전환 트리거**
- 카택스 요금에 불만
- 데이터 유실 사고 경험
- 엑셀 수동 취합 한계

## Persona D — 개인사업자 / 복식부기의무자 (로컬 모드 타겟)

**프로필**
- 연 매출 7,500만원 이상 개인사업자 (서비스업 기준)
- 차량 1대, 본인이 직접 운전
- 세무사에게 기장 위임하거나 직접 신고
- "회사" 개념 없이 혼자 씀

**현재 행동**
- 운행기록부 의무 있는 줄 모르거나 귀찮아서 안 씀
- 연말 세무사에게 맡길 때 자료 없어서 추정치로 신고

**핵심 니즈**
- 회사 코드 같은 복잡한 설정 없이 바로 쓰고 싶음
- 무료로 쓰고 싶음

**진입 경로 (로컬 모드)**
- 앱 설치 → 등록 화면 하단 "내 폰에만 운행기록 저장(무료)" 버튼 → 즉시 사용
- 회사 코드 불필요, 관리자 승인 불필요, 서버 연동 없음

**마케팅 포인트**
- "회원가입 없이 바로 시작" 강조
- 추후 "세무사에게 공유" 기능 연결 시 업셀 기회

## 현재 우선순위

1. **Persona B (세무사)** — 1명의 세무사 = 수십 명의 고객 확보 가능. 레버리지 최대
2. **Persona D (개인사업자)** — 로컬 모드로 진입 장벽 없음. 2024년 의무 확대로 시장 확대
3. **Persona A (소규모 법인 대표)** — 앱스토어 + SEO로 직접 유입
4. **Persona C (다차량 법인)** — 관리자 앱 기능 성숙 후 공략
