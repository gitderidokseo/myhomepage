# LalaCatSoft Homepage

This is the source code for the official website of LalaCatSoft, a premium software development company specializing in Mobile App Development and AI Solutions.

## Tech Stack

- **Core**: HTML5, CSS3, JavaScript (Vanilla)
- **Styling**: Custom CSS with responsive design
- **Fonts**: Google Fonts (Noto Sans KR, Noto Serif KR)
- **Icons**: FontAwesome

## Features

- Fully localized in Korean
- Responsive design for mobile and desktop
- Smooth scrolling and animations
- Contact form integration (frontend only)
