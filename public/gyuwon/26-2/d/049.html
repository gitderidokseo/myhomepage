종교와 사회복지 — 발표 주제 신청

제출 교수님 이메일발표일 11/24(화) 또는 12/1(화)마감 없음 — 선착순 선점

서두를 것

교수님이 "먼저 말하는 사람이 선점"이라고 했습니다. 마감은 없지만 지난주 수업에서 이미 여러 명이 주제를 확정했으므로, 원하는 주제가 있다면 빨리 보내는 것이 유리합니다.

이미 선점된 주제(중복 주의) — 성소수자, 웰다잉(죽음), 노인 빈곤, 이주민 의료, 아동 돌봄, 경계선 지능, 소수자 노인

1. 주제 구성 규칙

강의계획서의 주제1 × 주제2를 교차해서 만듭니다.

구분예시
주제1 — 영역아동복지 · 노인복지 · 장애인복지 · 소수자복지 · 의료복지 · 교정복지 · 군복지
주제2 — 이슈빈곤 · 폭력 · 학대 · 돌봄 공백 · 주거 · 사회적 배제 · 낙인(스티그마)

▸ 교수님 지적: "주제를 더 좁혀야 한다." "성소수자"처럼 넓은 주제는 그대로 쓸 수 없습니다.

2. 추천 주제 3안

아직 선점되지 않았고, 수업에서 다룬 개념(스티그마 / 잔여적·제도적 복지 / 신사회 위험)과 바로 연결되는 주제들입니다.

1안 — 교정복지 × 사회적 배제 (추천)

"출소자의 주거 지원과 낙인 — 교정복지가 지역사회에서 부딪히는 벽"

  • 왜 좋은가: 교수님이 "교정복지 하는 사람 자체가 얼마 없어 쉽지 않다"고 언급한 영역. 겹칠 가능성이 낮다
  • 수업 개념 연결: 스티그마(낙인) — 임대아파트 색깔 사례와 같은 구조 / 잔여적 복지의 한계
  • 종교와의 연결: 교도소 교화 활동은 전통적으로 종교기관이 맡아 온 영역

2안 — 노인복지 × 돌봄 공백

"농어촌 지역의 돌봄 격차 — 통합돌봄법은 지역 격차를 줄일 수 있는가"

  • 왜 좋은가: 교수님이 직접 길게 설명한 올해 3월 시행 통합돌봄법을 다룬다. 최신 제도라 자료가 많다
  • 수업 개념 연결: 신사회 위험(돌봄 공백) / 제도적 복지 / 아동복지 파트에서 언급된 정선군 어린이집 사례와 같은 구조
  • 주의: "노인 빈곤"은 이미 선점됨. 돌봄·지역 격차로 각을 잡으면 겹치지 않는다

3안 — 이주민·다문화 × 노동

"이주노동자의 산재와 의료 접근성 — 종교기관의 옹호(Advocacy) 활동을 중심으로"

  • 왜 좋은가: 교수님이 성공회의 이주민 사업과 노동자복지관의 애드보커시를 예로 들었다. 종교 연결이 가장 자연스럽다
  • 수업 개념 연결: 애드보커시 / 얼라이 / 모빌라이징 / 커뮤니티 오거나이징
  • 주의: "이주민 의료"가 선점되어 있으므로 산재·노동권으로 초점을 옮길 것
