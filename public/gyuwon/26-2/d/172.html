1부 — 文法の確認③ 포인트 3 작문 확인

1. 진행

  • 지난 수업에 이어 포인트 3(첨가) 작문 문제를 옆 학생과 함께 맞는 문장을 만들어 보고 확인 — 「2分考え(て)」, 「3問題…」
  • 녹취에 그림 힌트로 보이는 단어들이 들림: 家族(かぞく)·親戚(しんせき), 動物(どうぶつ), 環境問題(かんきょうもんだい), 雨(あめ)·風(かぜ)·雪(ゆき)·雷(かみなり)
  • 교수님: 이 포인트 부분 중 헷갈리는 곳은 (다음에) 한 번 더 확인하겠다

2. 포인트 3 작문 — 정리 (자료: 문법 확인③ 표현 목록.md)

표현 읽기 뜻 작문 예
〜上(に) 〜うえに ~에다가, 게다가 雨の上に風まで強くなってきた。 (あめのうえに かぜまで つよくなってきた) — 비가 오는 데다가 바람까지 세졌다
〜ばかりでなく 〜ばかりでなく ~뿐만 아니라 この水族館には魚ばかりでなくペンギンもいる。 (すいぞくかん / さかな) — 이 수족관에는 물고기뿐만 아니라 펭귄도 있다
〜に限らず 〜にかぎらず ~에 한하지 않고 環境問題は日本に限らず、どこでも深刻な問題です。 (かんきょうもんだい / しんこく) — 환경 문제는 일본뿐 아니라 어디서나 심각하다
〜はもちろん 〜はもちろん ~는 물론 家族はもちろん、親戚も祝ってくれた。 (かぞく / しんせき / いわって) — 가족은 물론 친척도 축하해 주었다

주의: A上にB의 B에는 명령·금지·의뢰·권유가 못 옴. ばかりでなく는 권유 가능(肉ばかりでなく野菜も食べよう).

2부 — 문법 복습 (문법 1 ~ 문법 3)

3. 복습 방법

  • 지금까지 한 문법이 한 장(프린트/화면)에 정리되어 있음: 문법 1 → 문법 2(명사화) → 문법 3(오늘 한 것)
  • 어휘(語彙)는 그냥 외워야 하는 영역이라 여기서 확인 안 하고 문법만 확인
  • 15분 자유 복습 — 혼자 해도, 같이 해도, 짝에게 설명해도 됨. 교수님: "말하면서 외우면 더 효과가 있다"
  • 답은 다 있다 (프린트에 답 있음)

4. 교수님이 짚어 준 곳 (녹취에서 알아들을 수 있는 부분)

내용 설명 확실도
しか + 부정 1번: 「しか」는 뒤에 부정형이 와야 함 → 「〜しかない」 (추정) "1번에 시간은… 부정형이기 때문에… 시가(しか)도 괜찮지만"
少ない는 명사 앞에 잘 안 옴 「少ない人(すくないひと)」처럼 い형용사 少ない로 명사를 바로 꾸미는 문장은 별로 없다 → 「人が少ない」 「少しの〜」로. 例: 슈퍼에 사람이 별로 없어요 → 「スーパーに人が少ない」 (추정) "형용사가 별로 문장에… 슈퍼에서… 이형사는 많이 없어요라고 말했어요… 이 부분이 문장 생각할 때 어려웠던 것 같아요"
だの = 마이너스 이미지 10번: 「〜だの〜だの」는 불만·부정적 느낌이 있는 말 녹취 "10번 이렇게 마이너스 이미지가 있는 거는"
やら는 범위가 넓다 「〜やら〜やら」는 커버할 수 있는 범위가 넓음 → 우선 "여러 가지(이것저것)" 정도로 기억. 「뭐 하든지 뭐 하든지」처럼 하나가 아닌 것을 늘어놓을 때 녹취 "커버할 수 있는 범위가 넓어요… 여러 가지다 정도에 생각하고"
명사화: 〜が → 〜の 「足が速い(あしがはやい)」를 명사로 만들면 「足の速さ」(あしのはやさ) — ✕「足が速さ」 / 「料理がうまい」 → 「料理のうまさ」 녹취 "아시가하야사가 아니라 아시노하야(사)… 료리가… 리노 마사(うまさ)"
단어만 외우지 말기 「速い→速さ」만 외우지 말고 문장 째로 (「AのBさ」 형태로) 확인 "하야사만 확인하지 말고 여기에 문장으로"
が냐 の냐 여러 예에서 「〜が」가 오는지 「〜の」가 오는지 조사를 주의 "이런 부분 확인해 주세요"

학생 질문(끝부분, ⚠ 불확실): 「少なくない(적지 않다)」 같은 표현 — 교수님 답 "원래 그렇게 외워야 하는 거" 정도로 들림 (?)

3부 — ことわざ(속담) 문제

5. 진행

  • 한국 속담과 비교하며 진행 (학생들: "돌다리도 두들겨 보고…", "돼지 목에 진주")

6. 나온 속담 (녹취 + 추정)

# 속담 읽기 뜻 비슷한 한국 속담 · 수업 설명
1 住めば都 すめばみやこ 어떤 곳이든 살다 보면 정들어 살기 좋아진다 학생: "산다면… 불편한 곳도 적응하면 괜찮다는 뜻". 교수님이 「都(みやこ)」·「都会(とかい)」 뜻도 설명. JLPT 기출
2 猫に小判 ねこにこばん 가치를 모르는 사람에게 귀한 것은 소용없다 「ねこは(お)金(の価値)がわからない」. 한국어 → 돼지 목에 진주
2' 豚に真珠 ぶたにしんじゅ (猫に小判과 같은 뜻) 교수님: 일본에도 「豚に…」라는 말이 있다
3 石橋を叩いて渡る いしばしをたたいてわたる 매우 조심스럽게 행동한다 돌다리도 두들겨 보고 건너라. ⚠ 「…違え(た)人多かっ(た)」 → 틀린 학생이 많았다고 들림
+ 石の上にも三年 いしのうえにもさんねん 참고 견디면 언젠가 이루어진다 (차가운 돌도 3년 앉아 있으면 따뜻해진다) 교수님 예: "새 회사에 들어가면 힘들어도 3년은 참아라" 같은 식으로 쓰는 말
+ 嘘も方便 うそもほうべん 경우에 따라서는 거짓말도 필요하다 학생: "거짓말도 방편". 교수님: 「場合によっては必要…嘘です」

「お金の価値はわかってる」(돈의 가치는 알고 있다) 같은 말도 들림 → 猫に小判 설명 중 (추정)

4부 — 관용 표현 ①~⑫ (들어 본 것만 확인)

7. 진행

  • 「1番から12まで読んでください」 → 2분 정도, 아는 것(들어 본 것)만 확인
  • 교수님: 이 중 몇 개는 앞에서 말한 것과 이어진다
  • 관용 표현이라 글자 그대로의 뜻이 아님 — 例: 「雷が落ちる」는 실제로 번개가 떨어지는 게 아니라 (윗사람에게) 호되게 혼난다는 뜻
  • 「JLPT で聞いたことあるな と思って」 — JLPT에서 들어 본 표현들, 「よく使う表現」
