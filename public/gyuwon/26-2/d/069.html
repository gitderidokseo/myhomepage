① 2주차 작문 과제 피드백

한국어 표현을 일본어로 옮기는 작문 — 교사가 자연스러운 일본어 표현을 짚어줌

한국어 발상 자연스러운 일본어 교사 코멘트
(장소가) 붐비다 混雑しています / 混んでいます 자주 쓰는 표현
처음부터 끝까지 계속 ~했다 ずっと〜していた (예: ずっと下を向いていた) 「ずっと」로 충분
감성적이다 感性がある 「感性的」는 일본어에서 별로 안 쓴다
(학생 질문) — "○○ 씨의 질문도 좋았어요"

② 포인트 2 — 예문 읽기와 작문

〜といったら — 감탄 · 정도가 대단함

예문 뜻
彼女の泳ぎ方のうまさといったら、まるで魚のようだ 그녀의 수영 솜씨라고 하면 마치 물고기 같다
キムさんの料理のうまさといったら、まるで〇〇のようです 김 씨의 요리 솜씨는 마치 ○○ 같아요

앞에 「うまさ」「早さ」「広さ」처럼 〜さ 명사가 자주 온다 → ④ 명사화와 연결 「まるで___のよう」에 들어갈 말 — 셰프 이름, 프로 요리사(コックさん / シェフ / プロの料理人) 등. 교사: 「コックさん」도 쓴다

〜にかけては — ~에 있어서는 (누구에게도 지지 않는다)

예문 뜻
あの子は走ることにかけては誰にも負けない 저 아이는 달리기에 있어서는 누구에게도 지지 않는다
私は〇〇にかけては誰にも負けない自信があります 나는 ○○에 있어서는 누구에게도 지지 않을 자신이 있습니다

★ 좋은 것에 사용. 「下手さにかけては」「まずさにかけては」라고는 거의 안 한다. 학생 답: マラソン / 水泳 / 情熱 / 英語 / スピーキング / 文法 / 料理 등

〜のこととなると — 그 얘기만 나오면 (보통 이상의 반응)

예문 뜻
田中さんは愛犬のこととなると、急に優しい性格になってしまう 다나카 씨는 애견 얘기만 나오면 갑자기 다정한 성격이 되어 버린다
田中さんは野球のこととなると、話が止まらない 야구 얘기만 나오면 말이 멈추지 않는다
父は仕事のこととなると目の色が変わる 아버지는 일 얘기만 나오면 눈빛이 달라진다

「目の色が変わる」 = 진지해지다, 열중하다 — "일에 대해 어떤 마음?" → 真面目な気持ち / 仕事が好き 뒤에는 「話が止まらない」「〜し続けてしまう」 등 다양한 표현 가능

〜に限って — 하필 ~할 때만

예문 뜻
休みの日に限って雨が降っています 쉬는 날에만 (하필) 비가 온다 — 가장 많이 나온 답
休みの日に限って早起きしてしまう 쉬는 날에만 일찍 일어나 버린다
傘がない日に限って雨が降る 우산 없는 날에 하필 비가 온다

그 밖에 학생 답: 친구가 없다 / 바쁘다 / 놀려고 해도 못 논다 등 「限る」는 1그룹 동사 — 월요일에 확인한 내용 재확인

〜というものは — 감정·가치 표현과 함께

예문 뜻
友情というものは素敵なものですね 우정이란 멋진 것이네요 (교사 작문)
友達というものは素敵なものですね 친구란 멋진 것이네요
恋というものは素敵なものですね 사랑이란 멋진 것이네요
人生というものは… 인생이란… (네이티브 작문)
魚というものは素敵なものですね 물고기란 멋진 것이네요 — 한 학생 답, 교사 "왜 물고기?" (웃음)

「お金持ち」 같은 답엔 "현실적이네요" 코멘트

③ 포인트 1·2 통합 연습 — 괄호에 A~K 중 골라 넣기

규칙 — 같은 것을 두 번 고를 수 없다 (각 1회만)

기호 표현 (전사 기준, 순서는 교재 확인)
A なら
B というのは
C といえば
D というと
E といったら
F とは
G というものは
… ~ K に限って / にかけては / のこととなると 등 (추정)

교사가 짚은 것

  • 「そういえば」가 여러 곳에 들어갈 수 있을 것 같지만, 「といえば」의 자리는 정해져 있다 — "여기에 쓰고 싶었던 건 이것"
  • 「足が出た」 = 예산 초과, 적자가 나다 — 교사·네이티브 모두 "요즘 별로 안 쓰는 표현"
  • 「思い浮かぶ / 思い浮かべる」 — 자동사/타동사 구별
  • 「〜のこととなると」 문항 — 아버지는 일 얘기만 나오면 目の色が変わる
  • 「寂しさ」 — 「一人暮らしを始めた時の寂しさ」 (혼자 살기 시작했을 때의 외로움)

④ 명사화 — 형용사 + 「さ」 / 동사의 명사형 ★

「うまさといったら」에서 이어진 연습. 괄호에 들어갈 말을 1분 정도 생각 → 발표. "답이 하나가 아닌 것도 있으니 천천히 생각하세요."

1) 「私は〇〇が好きです / 〇〇の〇〇を知らなかった」류 괄호 채우기

괄호 교사가 인정한 답
좋아하는 것 料理 / 料理をすること / 作ること (クッキング도 나옴)
지진의 ○○ 地震の怖さ / 危なさ / 危険性 (전사 「自震」 → 地震으로 추정) — 교과서 답은 「地震のニュース / 地震があった」도 가능
시간의 ○○ 時間の大切さ
피아노의 ○○ ピアノのうまさ

2) 동사 → 명사

원래 명사형 주의
山に登る / 山を歩く 山登り / 山歩き ★ 「山の歩き」라고는 안 한다. 「山歩き」는 산책에 가까운 가벼운 느낌, 「山登り」는 좀 더 가파른 느낌
ご飯を食べる 食事
本を読む 読書 영화 보기는 「映画鑑賞」 등
流れる 流れ
高まる 高まり
話す 話

3) 형용사 → 「さ」

원래 명사형 주의
美味しい 美味しさ
暑い 暑さ
綺麗だ 綺麗さ
部屋を掃除する 部屋の掃除 조사 の에 주의
足が速い 足の速さ
東京が良い 東京の良さ ★ 「良いさ」라고는 하지 않는다 — 주의
都市が便利だ 都市の便利さ 「便利な都市」로 쓴 학생도 있었음

마지막 4개(掃除·速さ·良さ·便利さ)는 조사(の)에도 주의 — 「〜が」가 「〜の」로 바뀐다

수업 흐름

  1. 출석 → 2주차 작문 과제 피드백
  2. 포인트 2 예문 1~5번 읽기 → 각 표현으로 작문 (페어, 2~3인)
  3. 학생 작문 발표·코멘트 (というものは / に限って / まるで〜のよう / にかけては / のこととなると)
  4. 포인트 1·2 통합 연습 (A~K 한 번씩만) → 페어 확인 → 교사 해설
  5. 명사화 「〜さ」·동사 명사형 연습
  6. 다음 시간 예고 — 비슷한 다음 부분 → 어휘 확인

이 수업에서 남길 것

  1. 「感性的」는 안 쓴다 → 「感性がある」, 붐비다는 「混んでいる / 混雑している」
  2. 「〜といったら」 앞에는 「〜さ」 명사가 잘 온다 (うまさといったら、まるで魚のようだ)
  3. 「〜にかけては」는 좋은 것에만 — 下手さ·まずさ에는 안 씀
  4. 「〜のこととなると」 = 그 얘기만 나오면 보통 이상의 반응 (目の色が変わる, 話が止まらない)
  5. 「〜に限って」 = 하필 그때 (休みの日に限って雨)
  6. 「山の歩き」 ✕ → 「山歩き」, 「良いさ」 ✕ → 「良さ」
  7. 명사화하면 「が」 → 「の」 (足が速い → 足の速さ)
  8. 「足が出る」 = 예산 초과 (요즘은 잘 안 씀)
