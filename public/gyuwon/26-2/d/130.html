0. 전체 줄거리 (한 문단)

2. 1막 — 사회: "노인이 많아서 큰일"이라는 숫자 (2주차 인구 고령화)

이야기: 뉴스는 "고령화 = 재앙"이라 한다 → 그런데 노화(개인) 와 고령화(사회) 는 다르고 → 부양비 같은 숫자는 가정을 깔고 있다 → 진단을 잘못하면 처방도 틀린다.

키워드 카드

  • 노화 vs 인구 고령화: 노화 = 개인의 변화(→ 건강·돌봄, 실천) / 고령화 = 인구 연령 구조의 변화(→ 연금·의료·노동시장·재정, 제도 설계).
  • 고령화가 생기는 길: 출생 감소(아래로부터) · 사망률 개선(위로부터) · 청년층 이동 → 오래 살지 않아도 아이가 줄면 고령화.
  • 노년부양비: 15~64세 100명당 65세 이상 인구 → 연령 구조 지표이지 실제 부양 부담 지표가 아님.
  • 숨은 가정: 65세 이상은 모두 부양받고, 15~64세는 모두 부양한다.
  • 65세 기준: 노인복지법엔 연령 정의가 없음, 개별 제도에서 굳어진 사실상 표준 → 실천 단위는 기능·소득·가구·지역이어야.
  • 한국 고령화의 핵심: 비율보다 속도. 속도에 비해 소득보장 제도가 덜 성숙 → 노인 빈곤 큼.
  • 위기 담론 비판 4가지: ① 인구학적 결정론(구조는 조건이지 운명 아님) ② 부양비 지표의 한계 ③ 세대 갈등 프레임 ④ 65세 기준 고정.
  • 진단이 처방을 바꾼다: "노인이 많은 게 문제" → 처방은 축소 / "제도가 미성숙한 게 문제" → 처방은 보완.

Q2 ★ 노년부양비의 한계

2072년 노년부양비 104.2명(참고) → "청년 한 명이 노인 한 명을 부양"이라는 해석의 문제를, 지표가 깔고 있는 가정을 중심으로 쓰라.

  • 정의: 생산연령(15~64세) 100명당 65세 이상. 계산은 맞지만, 결론은 가정을 사실로 받아들인 해석.
  • 한계 4가지 (교수님: "세 가지 정도 쓸 수 있으면")
    1. 65세+ = 모두 부양받는 사람? → 상당수가 일함(약 39%, 참고). 예: 2주차 65세 박정호 씨, 아파트 시설관리 주 5일, 스스로 생계.
    2. 15~64세 = 모두 부양하는 사람? → 학생·실업자·아픈 사람도 있음.
    3. 비시장 노동 빠짐 → 손자녀 돌봄, 자원봉사.
    4. 생산성 변화, 여성·고령자 노동참여 확대, 이민 반영 못 함.
  • 결론: 연령 구조 지표 ≠ 실제 부양 부담 지표. 숫자 하나로 "재앙" → 세대 갈등 프레임 + 노인 지출 줄이자는 엉뚱한 처방. 지표가 무엇을 전제하는지 먼저 확인.
  • ⚠ 실수: 한계를 하나만 쓰기 / "그러니 고령화는 문제없다"로 끝내기 → 비판의 요지는 "숫자 하나로 결론짓지 말자".

Q5 ● 노화 vs 인구 고령화

전남 고흥군 84세 정순임 씨: 무릎 관절염, 하루 네 번 오는 버스를 놓치면 세 시간 기다려야 해서 읍내 병원 가기 어려움. 누군가 "고령화 때문"이라 함 → 차이를 설명하고 비판하라.

  • 개념: 노화 = 한 사람의 신체 기능·역할·자기인식 변화 / 고령화 = 사회 속 노인 비중 증가(연령 구조 변화).
  • 대응도 다름: 노화 → 건강관리·돌봄(실천) / 고령화 → 연금·의료보장·노동시장(제도 설계). 고령화는 아이가 덜 태어나기만 해도 생김.
  • 사례 적용: 병원에 못 가는 이유 = 노인 비중 때문이 아니라 ① 관절염(개인의 노화·건강) + ② 하루 4번 버스(지역 교통 인프라, 지역 격차).
  • 비판: "고령화 탓" → 원인이 너무 커서 아무것도 바꿀 수 없음. 정확히 나누면 처방이 나옴 → 관절염엔 의료·재활 연계, 이동엔 교통 지원·찾아가는 의료. = 진단이 처방을 바꾼다.
  • ⚠ 실수: "개인/사회"로만 나누고 대응 차이와 사례 적용을 빼먹기.

3. 2막 — 몸: 넘어진 뒤 회복이 안 되는 이유 (3주차 신체적 건강)

이야기: 노화는 천천히, 누구에게나 온다 → 평소엔 괜찮지만 예비 능력이 줄어 큰일이 닥치면 버틸 힘이 없다 → 넘어짐 → 두려워서 안 움직임 → 더 약해짐(악순환) → 그래서 도울 때는 기준을 세워 우선순위를 정한다.

키워드 카드

  • 정상 노화 4특징: 점진적 · 보편적 · 비가역적 · 예비 능력 감소(가장 중요).
  • 예비 능력: 평소 기능이 아니라 수술·감염 같은 부하가 걸렸을 때 꺼내 쓸 여력.
  • 노화 vs 질병 구분: 노화는 느림 → 몇 달 사이 뚜렷한 변화면 질병·약물·환경 의심, "언제부터?"를 물음.
  • 구분 실패의 두 오류: ① 고칠 병을 "나이 탓"으로 덮기 ② 정상 노화를 병으로 다뤄 불필요한 검사·처방.
  • 성공적 노화와 비판: 3요소 = 질병 회피 · 기능 유지 · 사회 참여. 비판: 자원 없는 사람을 '실패'로 만들어 구조 문제를 개인 책임으로.
  • 복합이환 → 다약제: 여러 병원에서 따로 처방 → 약이 겹침. 사회복지사 역할 = 흩어진 처방을 모아 의료진에게 전달.
  • 노쇠: 질병 이전에 버틸 힘이 전반적으로 줄어든 취약 상태 → 낙상·입원·사망 위험↑.
  • 근감소증: 근육량 감소 + 근력·수행능력 저하 → 대응의 중심은 약이 아니라 운동과 영양.
  • 낙상: 우연이 아니라 개인·환경·행동 요인이 쌓인 결과. 환경 개선은 결국 돈(불평등) 의 문제.
  • 낙상 두려움의 악순환: 넘어질까 봐 안 움직임 → 근력 저하·고립 → 낙상 위험↑ → 반복.
  • 청각 손실의 경로: 안 들림 → 대화 회피 → 고립 → 우울 → 정보·서비스 접근 끊김.
  • ADL vs IADL: IADL(장보기·전화 등)이 ADL(식사·화장실 등)보다 먼저 손상 → IADL 변화를 잡으면 더 일찍 개입.
  • 기대수명 − 건강수명: 약 18년(참고) = 만성질환·기능 제한을 안고 사는 기간 → 목표는 이 기간 줄이기.
  • 우선순위 기준: 시급성 · 실현 가능성 · 지속 가능성 · 효율성 · 당사자의 선택 (+ 정해진 시간 안에 할 수 있는가).

Q7 ★ 최영자 씨 — 개입 우선순위와 근거

79세 최영자 씨: 새벽 화장실 가다 넘어져 고관절 골절 → 수술 성공, 6주 뒤 퇴원, 그러나 혼자 화장실 못 감 → 5개월 뒤 장기요양 4등급, 주 3회 방문요양 → 재활병원 두 달째 못 감 → 집 밖에 안 나가고 이웃과 연락 끊김 → 돌보는 82세 남편도 관절염, 부쩍 말이 없어짐 → 기록: "골절은 치료되었으나 회복되지 않았음." 문제: 회복을 막는 요인 분석 + 가장 먼저 할 개입 하나와 근거.

  • 요인 분석 (의료 / 비의료로 나누기)
    • 의료: 재활 못 받음 → 근력 더 저하 위험.
    • 비의료: 이동 수단 없음 · 주거환경(문턱·손잡이·조명) 그대로 · 이웃 단절 · 남편의 관절염과 소진.
    • 경계: 낙상 두려움(약물, 남편 우울도 경계가 흐릿).
  • 연결고리: 예비 능력 감소 → 큰 부상 뒤 회복 느림 + 낙상 두려움의 악순환(안 움직임 → 근력↓ → 재낙상 위험↑).
  • 1순위 = 주거환경 개선(화장실까지 문턱 제거 · 손잡이 · 야간 조명)
    1. 시급성: 재낙상 방지.
    2. 실현 가능성·효율성: 재활병원 이동보다 돈·시간 적게.
    3. ADL 기본선: 혼자 화장실 가기는 지켜져야 할 기본. 공간이 안전해야 재활·사회 활동도 가능.
  • 이어서: 재활병원 이동 지원, 남편 돌봄 부담 지원(돌봄자 소진) → 다음 순위.
  • 마지막 열쇠: 무엇을 먼저 할지는 최영자 씨 본인이 원하는 것을 확인하고 정함.
  • ⚠ 실수: 1순위만 쓰고 기준(왜 먼저인지) 빼기. 교수님은 정답보다 기준 + 근거를 봄. 수업에선 대부분 주거환경을 골랐지만, "심리적 고립·남편과의 소통" 1순위도 근거가 있으면 인정되는 분위기.

4. 3막 — 관계: 혼자 사는 세 사람, 누가 가장 위험한가 (4주차 독거노인)

이야기: 세 사람이 다 혼자 산다 → 그러나 독거(사실) · 고립(양) · 외로움(질) 은 다른 문제 → 고독사 숫자는 정의가 넓어져서 늘었고, 가장 위험한 건 중장년 남성 → 그런데 그는 신청을 안 해 명단에 없고, 문도 안 연다 → 행정 기준과 실제 위험이 어긋날 때, 사회복지사가 판단하고 기록한다.

박성호(68세 남성) 이혼 · 자녀와 연락 끊김 · 무소득 · 원룸 · 저녁을 술로 · 방문 거부 · 기초연금 미신청 고립 (고독사 고위험)
정순덕(76세 여성) 자가·연금 · 사별 3년 · 딸이 이틀에 한 번 전화하면 "잘 지내" · 아침 결식 · 소리 채우려 TV 켜 둠 외로움 (고립 아님)

키워드 카드

  • 독거 = 혼자 한 가구를 이루는 사실. 그 자체로는 문제 아님(문제의 '표지').
  • 사회적 고립 = 접촉하는 사람 수·빈도·도움 요청할 대상 → 관계의 양, 객관.
  • 외로움 = 원하는 관계와 실제 관계의 간극에서 오는 고통 → 관계의 질, 주관.
  • 세 개념별 대응: 독거 → 안전 확인 / 고립 → 관계망 형성 / 외로움 → 관계의 질·의미 있는 역할 회복.
  • Holt-Lunstad(2015) 메타분석: 고립·외로움·독거 모두 다른 요인 통제해도 사망 위험↑, 그 힘은 65세 미만 표본에서 더 큼.
  • 1인 가구와 건강의 인과: 방향 확정 불가(독거→건강 악화 / 역인과 / 제3요인). 그래도 "지원이 더 필요하다"는 결론은 같음.
  • 접근 거부의 배경: 수치심·낙인 · 과거의 실망 · 우울로 인한 무기력 · 도움 요청을 실패로 여김.
  • 문을 열지 않는 것 = 위험이 낮다는 근거가 아니라 높다는 신호 → 한 번 거부로 종결하지 않음.
  • 고독사 정의 변화: 홀로 사는 사람(2022) → 사회적 고립 상태로 생활하던 사람(2023.6) → '일정 시간 뒤 발견' 요건 삭제(2024.2).
  • 고독사 통계 읽기: 정의가 넓어져 해마다 그대로 비교 불가. 가장 취약 = 중장년 남성.
  • 절대 수 vs 발생률: 두 지표가 다른 이야기를 함 → 함께 읽기.
  • 신청주의의 한계 vs 대상 기준의 한계: 자격 있어도 신청 안 함(→ 찾아가는 발굴) / 신청해도 요건 미달(→ 기준 재설계).
  • 기준 A vs 기준 B: 행정적으로 확인 가능한 기준(소득·기능)과 실제 위험도는 일치하지 않을 수 있음.
  • 무연고 사망: 죽음의 방식이 아니라 시신을 인수할 사람이 없는 행정적 상태. 다수는 가족이 있는데도 인수 거부·기피.

Q6 ● 독거 · 고립 · 외로움 구분

세 사람 모두 혼자 산다 → 세 개념의 차이와, 사람마다 개입이 왜 다른지.

  • 개념: 독거 = 사실 / 고립 = 관계의 양(객관) / 외로움 = 관계의 질(주관적 고통).
  • 사례 적용
    • 김말순: 혼자여도 관계망 있음 → 고립 아님 → 관계를 유지할 조건(이동·건강) 지원.
    • 박성호: 연락 끊김 + 방문 거부 = 고립 → 관계 만들기 전에 접촉 자체를 여는 접근(① 이익이 되는 용건 앞세우기 ② 아는 사람 통하기 ③ 여러 번 시도).
    • 정순덕: 딸과 연락하니 고립 아님, 그러나 TV로 소리 채우기 = 외로움 → 의미 있는 역할·관계의 질 회복.
  • 핵심: 혼자 사는 것 자체가 문제가 아님 → 어떤 문제인지 진단해야 개입이 정해진다.
  • 현장 오류: 측정 쉬운 안부 확인으로만 셋 다 처리. 안부 확인은 늦게 발견되는 것은 막아도 고립·외로움 자체는 못 줄임.
  • ⚠ 실수: "혼자 살면 외롭다"처럼 한 덩어리로 쓰기.

Q3 ★ 고독사예방법 정의 변화와 통계 해석

고독사 2017년 2,412명 → 2024년 3,924명(참고). 법 정의 변화를 근거로 이 숫자를 어떻게 읽을지 + "고독사 = 독거노인 문제" 통념 검토.

  • 정의 변화 3단계
    1. 처음: "홀로 사는 사람이 … 시신이 일정 시간 흐른 뒤 발견되는 죽음"(2022)
    2. 2023.6 개정: "사회적 고립 상태로 생활하던 사람"
    3. 2024.2 개정: "시신이 일정 시간 흐른 뒤 발견" 요건 삭제
  • 의미 ①: 관심이 독거 → 사회적 고립으로 이동.
  • 의미 ②: 정의가 넓어짐 = 같은 현실이라도 세는 범위가 커짐 → 2017과 2024는 다른 기준으로 센 숫자, 증가분 전체를 "그만큼 늘었다"로 읽으면 안 됨.
  • 통념 검토: 2023 자료 50·60대 합쳐 약 61.8%, 70대 이상 18.7%, 남성 84.1%(참고) → 가장 취약 = 중장년 남성.
  • 함의: 노인맞춤돌봄 등은 65세 기준 → 통념대로 정책 짜면 가장 위험한 사람을 놓침.
  • 균형: 인구 10만 명당 발생률로 보면 순위가 달라짐 → 노인 고독사가 안 중요하다는 뜻 아님, 절대 수와 발생률을 함께.
  • ⚠ 실수: "정의가 바뀌었다"만 쓰고 그래서 숫자를 어떻게 읽나(비교 불가) 를 빼먹기.

Q9 ★ 세 사람 중 누구 먼저 — 기준 A vs 기준 B

행정적 기준(소득·기능)과 위험도 기준으로 각각 순위 → 둘이 다를 때 어떻게 판단?

  • 기준 A(소득·기능): 김말순 1순위(수급자) / 정순덕은 연금·자가라 노인맞춤돌봄 소득 요건 미달 / 박성호는 기초연금 미신청이라 명단에 없음.
  • 기준 B(위험도): 박성호 1순위 → 중장년 · 남성 · 이혼 · 연락 두절 · 무소득 · 음주 · 원룸 · 방문 거부 = 고독사 고위험 프로필. 문을 안 여는 것 자체가 위험 신호("접촉 실패" → "고위험군, 접근 전략 재수립").
  • 나머지 두 사람: 김말순 = 이미 연결됨 → 유지 지원 / 정순덕 = 지금 위험은 크지 않지만 결식 → 근육 감소 → 낙상으로 이어질 수 있어 예방 효과가 큰 사람.
  • 박성호 접근법: 급여 신청 안내처럼 본인에게 이익이 되는 용건 앞세우기 + 여러 번 찾아가기.
  • 어긋남 두 가지
    • 박성호 = 신청주의의 한계 → 찾아가는 발굴.
    • 정순덕 = 대상 기준의 한계(사각지대) → 기준 재설계 또는 지역 이웃 관계 같은 제도 밖 자원.
  • 마무리: 사회복지사가 이 간극을 메우는 판단을 하고, 근거를 기록으로 남긴다.
  • ⚠ 실수: "가장 나이 많아서", "가장 불쌍해서" → 교수님: "불쌍해 보여서는 근거가 아니다."

5. 4막 — 마음: 깜빡하는 게 다 치매는 아니다 (5주차 인지건강)

이야기: 나이 들면 어떤 능력은 떨어지고 어떤 능력은 그대로다 → 이상해 보여도 우울·약·귀·몸이 원인일 수 있다 → 그 사이에 MCI라는 "개입의 창"이 있다 → 유병률 숫자도 분모를 봐야 한다 → 위험요인은 비난이 아니라 예방의 도구 → 마지막으로, 검사를 거부하는 김 씨 앞에서 무엇을 할 것인가.

키워드 카드

  • 저하 영역 vs 유지 영역: 처리 속도·작업기억·새 정보 기억·주의 ↓ / 어휘·지식·익숙한 절차·정서 조절 유지.
  • 판별 3질문: ① 일상 기능에 영향이 있나 ② 익숙한 일에서 문제가 생기나 ③ 잊었다는 사실 자체를 아나 → 판별이지 진단이 아님.
  • 감별 4가지: 우울(첫 번째) · 약물 · 감각 손실 · 신체 질환(섬망 포함) → 치매처럼 보여도 원인을 없애면 상당히 회복.
  • 섬망: 수술·입원·환경 변화·강한 약물 등으로 갑자기 생기는 혼동 상태 → 치매와 다름.
  • 경도인지장애(MCI): 객관적 검사로 확인되는 저하 + 일상생활 능력 유지 → 반드시 치매로 가지 않음.
  • 개입의 창: MCI는 치매 위험이 높지만 관리하면 회복 여지 → 개입하기 가장 좋은 때.
  • MCI 결과 전달: "지금 치매는 아니다" + "지켜보기만 할 상태도 아니다" 함께.
  • 치매: 병명이 아니라 여러 원인 질환으로 일상생활에 지장이 생긴 증후군.
  • 유병률 하락의 함정: 베이비붐 세대 진입으로 분모↑ → 비율↓, 환자 수는 줄지 않음.
  • 선별 vs 진단: 선별검사 인지저하자 비율 ≠ 진단에 따른 치매 유병률(다른 숫자).
  • 독거와 인지 저하: 인과는 확정 불가. 실천에서 중요한 점 = 혼자 살면 변화를 알아차려 줄 사람이 없다.
  • 란셋 위험요인: 14개, 생애 전체에 걸침 → 예방의 도구이지 비난의 도구가 아님.
  • 사회복지사와 검사: 교재 "검사를 수행하는 것이 아니라 연결하는 것" / 교수님 "선별검사는 해 볼 수 있고, 진단 검사는 의뢰" → 둘 다 알아 두기.
  • 검사 권유의 원칙: 감별 먼저 → "치매"를 앞세우지 않고 관찰 사실 + 걱정 + 제안 → 효과 과장 금지 → 자기결정권 존중.

Q8 ● MCI vs 치매, 그리고 감별

73세 한복순 씨: 30년 다닌 시장 길에서 헤맴 · 김치 담그는 순서를 중간에 멈춤 · 은행 창구에서 설명을 여러 번 되물음. 그러나 어휘 풍부, 손녀에게 조언 잘함. 검사 결과 "치매 아님, 경도인지장애."

  • 개념: MCI = 기억력·언어능력·지남력 등이 객관적 검사로 확인될 만큼 저하 + 일상생활 능력 유지 / 치매 = 여러 원인 질환으로 일상생활에 지장이 생긴 증후군. → 가르는 기준 = 일상생활을 해내느냐.
  • 사례 적용: 시장 길·김치 순서 = 익숙한 일에서의 문제 → 정상 노화로 보기 어려움. 그러나 어휘·조언(유지 영역) 그대로, 생활도 꾸림 → MCI.
  • 전망: 치매 전환 위험 매년 10~15%(참고), 그러나 반드시 진행하지 않음. 관리하면 정상 회복 약 30%(참고 — 교수님: 확률 표집 연구가 아니라 단정 불가) → 개입의 창.
  • 감별 먼저: 우울(노년기엔 기억력 감퇴로 나타남) · 약물 · 감각 손실(은행에서 되묻기 = 청력일 수도) · 신체 질환 → 원인 없애면 상당히 회복.
  • 전달: "지금 치매는 아니다" + "지켜보기만 할 상태도 아니다" → 방치도, 불필요한 겁도 막음.
  • ⚠ 실수: MCI를 "치매 초기"로 쓰기 / 감별 없이 바로 "치매 의심 → 검사".

Q4 ● 치매 유병률 하락을 어떻게 읽나

65세+ 치매 유병률 2016년 9.50% → 2023년 9.25%(참고). "치매가 줄고 있다" 보도의 문제 + 실천에 주는 의미.

  • 개념: 유병률 = 환자 수 ÷ 65세 이상 인구 = 비율 → 분모에 따라 달라짐.
  • 원인: 1차 베이비붐 세대(1955~1963년생) 가 65세에 진입 → 노인 인구 크게 증가(약 268만 명, 참고). 새로 들어온 젊은 노인은 치매 비율 낮음 → 분모가 커져 비율이 내려간 것.
  • 실제: 환자 수(절대 수)는 2025년 약 97만 명에서 계속 증가 추정(참고). MCI 유병률은 오히려 22.25% → 28.42%로 상승(참고).
  • 위험: 보도를 믿으면 치매 예산·인력을 줄여도 된다는 잘못된 판단.
  • 실천 의미: 돌봐야 할 사람 수는 늘고 있음 → 특히 MCI 단계를 조기에 찾아 연결. = 2주차 원칙 "비율과 절대 수는 다른 이야기를 한다, 지표가 무엇을 재는지 확인하라."
  • ⚠ 실수: "유병률이 줄었으니 예방 정책이 효과 있었다" → 자료에 그런 근거 없음.

Q10 ● 위험요인 목록 — 예방의 도구인가, 비난의 도구인가

란셋 위원회(2024): 수정 가능한 위험요인 14개, 관리하면 상당수(약 45%, 참고) 예방 가능 → 실천에서 어떻게 쓸까?

  • 생애 전체: 청장년기 저학력 / 중년기 청력 손실·고콜레스테롤·우울 등 / 노년기 사회적 고립 등 → 예방은 노년에 시작할 일이 아니라 생애 전 단계의 과제.
  • 청력 손실의 경로: 안 들림 → 되묻기 → 대화 회피 → 관계 축소 → 인지 자극↓ → 인지 저하. 보청기로 교정 가능 = 개입 가능한 요인.
  • 사회적 조건: 교육·신체활동·고립·우울 = 개인 노력만으로 바꾸기 어려운 생활 조건. 실제로 저학력·농어촌일수록 유병률↑.
  • 두 갈래: "술 마시고 운동 안 한 당신 탓" → 비난의 도구 / 교육 기회·안전하게 걸을 환경·관계망 유지 조건·우울 치료·보청기 접근성 등 조건을 바꾸는 근거 → 예방의 도구.
  • 결론: 교수님 "예방의 도구이지 비난의 도구가 아니다."
  • ⚠ 실수: 위험요인 나열만 하고 핵심인 "누구의 책임으로 읽느냐" 를 빼먹기.

Q1 ★★ 검사를 거부하는 김 씨 — 다음에 무엇을 하겠는가 (직접 출제 예고)

사례(9/30 녹취로 복원, 활동지 원본과 대조 필요): 나는 노인맞춤돌봄 생활지원사. 2년째 방문하는 김○○ 씨 → 지난달 방문 약속을 두 번 잊음 · 30년 다닌 시장에서 길을 헤맸다는 얘기를 이웃에게서 들음 · 본인은 "나는 아직 정정해"를 자주 말함 · 오늘 이 얘기를 꺼내려 함. (활동지 1번: 검사 전 확인할 것 4가지 + 물어볼 말 / 2번: 검사 권유 문장) 5번: 김 씨가 "괜찮다니까, 그런 거 안 해"라고 하면 다음에 무엇을 하겠는가? 설명하고 적절히 쓰라. 교수님: "요거는 중간고사 문제로 (나옵)니다. 설명을 하고 무엇을 하겠는가를 적절히 적는 것." (교수님 정답은 녹취에 없음 → 아래는 2~5주차 내용을 묶은 답)

이야기 흐름으로 외우기: 받아들이고 → 이해하고 → 확인하고 → 다시 권하고 → 기록·연결

  1. 거부 = 끝이 아니라 다음 개입의 시작점. (4주차: 한 번 거부로 종결하지 않기)
  2. 이해: 거부의 배경 = 수치심·낙인 두려움, 과거의 실망, 우울로 인한 무기력. "나는 아직 정정해" 속엔 '치매 환자로 보일까' 하는 두려움.
  3. 받아들이기: 자기결정권 존중 → 그 자리에서 밀어붙이지 않음. "네, 알겠어요. 어머님이 싫으시면 오늘은 안 해요." → 관계를 지킴. 2년간 쌓은 신뢰로 다음 방문에 다시 얘기할 문을 열어 둠.
  4. 판단 근거 기억: 30년 다닌 시장에서 길 잃음 = 익숙한 일에서의 문제 → 흔한 건망증으로 넘기기 어려움.
  5. 감별 먼저(치매로 단정 전), 일상 대화 속에서
    • 우울: "요즘 기분은 어떠세요?"
    • 약물: "드시는 약이 바뀌셨어요?"
    • 감각: "TV 소리는 잘 들리세요?"
    • 신체: "최근에 아프신 데는 없으셨어요?"
  6. 다시 권할 때: "치매 검사"를 앞세우지 않고 관찰 사실 + 걱정 + 제안 → "제가 요즘 어머님이 길에서 고생하셨다는 얘기를 듣고 걱정이 돼서요. 확인만 해 두셔도 마음이 편해지실 것 같은데, 한번 같이 가 보실래요?" + "검사 받으면 좋아진다"처럼 효과를 부풀리지 않기.
  7. 기록·연결: 방문마다 본 변화를 판단이 아닌 관찰 사실로 기록 → 전담사회복지사와 공유 → 필요하면 치매안심센터 선별검사로 연결.
  8. 근거 한 줄: 사회복지사의 역할 = 검사를 강요하는 게 아니라, 당사자가 스스로 선택할 수 있게 신뢰와 정보를 주고 연결하는 것.
  9. 채점 키워드: 종결하지 않기 · 거부 배경 이해 · 자기결정권(강요·겁주기 금지) · 감별 4가지 · 익숙한 일 · 낙인 없는 말("치매 아니세요?" 금지) · 효과 과장 금지 · 관찰·기록 · 연결 · 다시 권할 통로.
  10. ⚠ 실수: "거부했으니 존중하고 끝" ↔ "위험하니 가족에게 알려 억지로 검사" → 둘 다 한쪽만 본 답.
