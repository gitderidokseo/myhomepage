① 「〜り」 부사 — 정리 + A~R 정답

1) 월요일 내용 정리 (녹취)

  • 27번 「つまり」는 빼 주세요 — 부사가 아니라 접속사("즉, 다시 말해") → 26번까지
  • 괄호 안 형태(「やはり(やっぱり)」 「あまり(あんまり)」)는 의미 차이가 없고 구어/형태 차이일 뿐 (녹취엔 "21번·24번"으로 들림 → 목록상 ㉒・㉔ (?))
  • ⑰ぴたり와 ⑱ぴったり는 비슷하지만 차이가 조금 있다 → 오늘 다룸
  • 오늘은 A~R을 페어로 한 번 더 확인 → 헷갈리는 쌍 찾기 → 차이 확인

2) A~R 정답

정답은 PPT(5주차 어휘 확인③) 기준 (자료). 녹취에서 교사 설명이 들린 곳만 "수업 설명"에 적었습니다.

# 문장 정답 수업 설명 (녹취)
A 一卵性の双子だけあって顔が( )ですね。 そっくり
B このくつ、私の足に( )です。 ぴったり
C 今日も明日も予定が( )つまっています。 ぎっしり "오늘도 내일도 예정이 (꽉) 있습니다"
D 部下たちにもっと( )仕事をしてほしい。 しっかり "좀 더 제대로 일을 하면 좋겠다"
E 何か( )したものが食べたいなあ。 さっぱり
F 30年も経つと、町の様子も( )変わってしまう。 すっかり
G あんなにがんばったのに、結果に( )してしまった。 がっかり "결과에 (실망)해 버렸다"
H あせらないでいいですよ。時間なら( )ありますから。 たっぷり "시간이 많이 있다"는 의미
I 後ろを振り返ったら、歩いていた犬が( )止まった。 ぴたりと 움직임이 멈출 때 쓰는 말. 「ぴったり」라고 하면 밀착의 의미가 됨
J 昨日、駅のホームで、知人に( )会った。 ばったり 「いきなり」를 고른 학생도 → 차이는 ②에서
K 睡眠不足で一日中( )していた。 ぼんやり
L ( )休んだので、もう元気になりました。 ゆっくり 「ぐっすり」(→ぐっすり寝る)도 언급된 듯 (?)
M 本だなに本が( )ならんでいる。 ずらり(と) · (ぎっしり) 「ぎっしり」를 고른 학생도 있을 것 — 둘 다 괜찮지만 뉘앙스가 다르다 → ②에서
O 最近( )寒くなりましたね。 めっきり · (いきなり)
P ノックもしないで( )部屋に入って来られてびっくりした。 いきなり · (こっそり) 갑자기 들어오는 느낌. 학생: "O와 P 둘 다 いきなり가 들어가는 것 같다(중복 가능)"
Q 言いたいことをすべて言ったので、気分が( )しました。 すっきり 「さっぱり」는 조금 어색 — 왜 그런지 나중에(②) 생각하자
R 最近ずっと忙しいので( )したい。 のんびり · ゆっくり

유인물에 N번은 없음 (M 다음이 O).

페어 토론에서 학생들이 헷갈린 쌍 (한국어 대화)

  • ばったり vs いきなり — 둘 다 "갑자기" 같은데 무엇이 다른지
  • すっかり vs めっきり — 학생 의견: 「すっかり」는 거의 완전히(90% 이상) 바뀐 것, 「めっきり」는 상당히 바뀌어 가는 정도
  • さっぱり vs すっきり — 학생: "지난번에 さっぱり는 성격에 쓸 수 있는 단어라고 하셨죠?"
  • ぴたり vs ぴったり — 하나는 딱 들어맞음, 하나는 딱 끊기는 느낌

② 비슷한 부사의 차이 (ことばの確認③のつづき) ★

교사: "이미지로 괜찮다(イメージでかまいません)." 맞다/틀리다가 아니라 이미지로 구별하자. 교사 여담 — 한국어에도 이런 비슷한 말이 정말 많아서 어렵다. 언어에 비슷한 말이 둘 다 남아 있는 건 어딘가에 차이가 있기 때문 — 차이가 없으면 한쪽이 흡수되어 사라진다. 교사도 준비하며 공부가 많이 됐다고 함.

쌍 예 (자료) 차이 (해설 유인물) 수업 설명 (녹취)
A. ばったり / いきなり ばったり会う · となりの人がいきなり話しかけてきた ばったり → 누군가와 우연히 만났을 때<br>いきなり → 갑자기(예고 없이) 행동하거나 일어났을 때 いきなり = 예고 없이 일어났을 때로 생각하면 된다. 「ばったり」와 잘 어울리는 동사는 会う
※ 「連絡がばったり途絶えました。」의 뜻은? 연락이 갑자기 끊겼어요 0928에도 나온 예
B. ぴたり / ぴったり ぴたりと止まる · 計算がぴったり合う ぴたり → 정지, 동작이 갑자기 멈출 때<br>ぴったり → 잘 어울릴 때, 숫자 등이 일치할 때<br>밀착할 때는 ぴたり(と)·ぴったり(と) 둘 다 (くっつく) 밀착은 둘 다 괜찮다. 존재·동작이 갑자기 멈출 때는 ぴたり → 멈추는 동사가 잘 어울림. 일치할 때는 ぴったり. ぴったり를 멈출 때 못 쓰는 건 아니지만 일치할 때 더 잘 어울림
C. のんびり / ゆっくり のんびり過ごす · ゆっくり過ごす のんびり → 마음 상태에 여유<br>ゆっくり → 속도나 시간에 여유 "쉬고 싶다"는 의미로는 차이 없음. 하지만 속도에 관한 것엔 のんびり가 잘 안 어울린다. 예: 「ゆっくり休んでください」
D. さっぱり / すっきり さっぱりした · すっきりした さっぱり → 상쾌함 (땀 등이 없어진 상태)<br>すっきり → 상쾌함·명쾌함 (찜찜한 것, 마음에 걸리는 것이 해결되어서) すっきり는 명쾌함에 가깝다 — 마음이 モヤモヤ하던 게 해결됐을 때. 어려운 문제가 풀렸을 때는 すっきり. さっぱり는 땀 같은 것에 시점, すっきり는 전체적으로 느끼는 것
※ 「さっぱりわかりません。」의 뜻은? 전혀 모릅니다 「さっぱり」에는 すっきり에 없는 "전혀"라는 의미가 있다
※ 사람 성격에 쓸 수 있는 것은? — さっぱり — 성격이 시원시원하다, (화가 나도) 계속 마음에 담아 두지 않는다는 느낌 (0928: すっきりした性格는 거의 안 씀)
E. ぎっしり / ずらり(と) 本がぎっしりつまっている · 本がずらりとならんでいる ぎっしり → 밀도<br>ずらり(と) → 일렬로 늘어놓은 상태 ⚠ 녹취 거의 복원 불가 (「人並…」 정도만 들림)
F. めっきり / すっかり めっきりすずしくなった · すっかりすずしくなった めっきり → 변화(계속)<br>すっかり → 변화(완료) 변화하고 있는 상태 vs 완료된 상태의 차이. 「완전히 잊어버렸다」는 완료이므로 すっかり忘れた — 「めっきり」로는 말할 수 없다

③ 文法の確認③ — 스타트 테스트 (ポイント1~3)

교사(한국어): "이건 앞으로 이런 걸 하겠다는 소개" — 지금 모르는 것은 체크하고, "이건 비슷한 표현이네" 싶은 것도 체크. 예로 ①을 함께: 「오래된 노래를 소재로 해서 만들어졌다」 → 「소재로 해서」 쪽인지, 「〜のもとで」(~ 밑에서) 쪽인지 → 이런 것을 나중에 한다. 이어서 ②~⑫를 페어로 — "이쪽이 맞는 것 같다/저쪽이 맞는 것 같다 싶은 부분이 있을 것" — 네이티브도 헷갈리는 것이 있으니 많이 읽어 보며 감으로.

# 문제 (자료) 정답 ⚠ (수업에서 미확인 — 자료 PPT의 설명 기준 추정)

② この工場では厳しい管理(A.をもとにして B.のもとで)食品が作られている。 B. のもとで

④ 新聞は事実(A.に基づいて B.のもとで)記事を書かなければならない。 A. に基づいて
⑤ ドーム球場では天気(A.もかまわず B.にかかわらず)試合ができます。 B. にかかわらず
⑥ うわあ、あの人たち、人目(A.もかまわず B.を問わず)けんかしているよ。 A. もかまわず
⑦ 雨の日(A.は別として B.にかかわりなく)、それ以外の日は毎日ジョギングしています。 A. は別として
⑧ 仕事の内容(A.にかかわりなく B.はさておき)、時給には満足している。 B. はさておき
⑨ この部屋、せまい(A.うえに B.に限らず)、とても古い。 A. うえに
⑩ 自分のこと(A.ばかりでなく B.のうえに)、相手のことも考えましょう。 A. ばかりでなく
⑪ ここはいつも人が多い。週末(A.は別として B.に限らず)、平日もたくさんの人でにぎわっている。 B. に限らず
⑫ 病気の治療(A.を問わず B.はもちろん)、予防にも努力しています。 B. はもちろん

페어 대화에서 들린 것 (한국어)

  • ⑤ 날씨 — "날씨와 관계없이"
  • ⑦ 비 오는 날 — "비 오는 날에는 안 하고 (나머지 날은 달린다)"
  • ⑧ — "일 내용은 별로 상관없고 시급은 마음에 든다"
  • ⑫ — "치료는 물론 예방도"

이 수업에서 남길 것

  1. ばったり = 우연히 만남 (ばったり会う), いきなり = 예고 없이 갑자기. 「連絡がばったり途絶えた」 = 연락이 뚝 끊겼다
  2. ぴたり = 멈춤 (ぴたりと止まる), ぴったり = 일치·잘 어울림 (計算がぴったり合う), 밀착은 둘 다
  3. のんびり = 마음의 여유, ゆっくり = 속도·시간의 여유
  4. さっぱり = 땀 등이 사라진 상쾌함 / 성격 / 「さっぱりわからない」= 전혀, すっきり = 걸리던 것이 해결된 명쾌함
  5. ぎっしり = 밀도, ずらり = 일렬로 늘어섬
  6. めっきり = 변화 진행, すっかり = 변화 완료 (すっかり忘れた)
  7. 비슷한 말이 남아 있는 건 차이가 있기 때문
  8. 다음은 文法の確認③ (をもとに・のもとで・に沿って・に基づいて …)
