3. 포인트 1 — 조사(助詞)의 의미

수업 진행 방식: ① 조사라고 하면 떠오르는 것을 10개 정도 적어 보기 → ② A~J까지 각 조사의 의미 확인 → ③ 스타트 테스트(1~10번, 100점 만점) → ④ 페어로 예문 만들기

핵심 조사 정리

조사뜻뉘앙스 / 예문
だけ~만 (only)중립적. ビールだけ飲む (맥주만 마신다)
다른 의미도 있다 → 好きなだけ(원하는 만큼), できるだけ(가능한 만큼), 食べたいだけ
ばかり~만 (계속)부정적 뉘앙스가 강하다.
ラーメンばかり食べる / 寝てばかり / 遊んでばかり / 飲んでばかり
→ 勉強ばかりしてはいけません
さえ~만 (조건) / ~조차～さえ～ば 형태로 자주 쓴다.
時間さえあれば / お金さえあれば / 窓さえ拭けば掃除が終わる
또 子供さえ知っている(아이조차 안다)
しか~밖에반드시 부정과 함께 쓴다.
教室に私しかいません / 待つしかない
も~씩이나 (강조)수량 강조.
1日に3回もご飯を食べる / 5回も歯磨きをする / 10時間も寝る
반대: 1日に1回しか食事しない
가장 헷갈리는 지점 — だけ vs ばかり

둘 다 "~만"으로 번역되지만 ばかり는 부정적 평가가 실린다.

ラーメンだけ食べる = 라면만 먹는다 (사실 진술)
ラーメンばかり食べる = 라면만 먹어 댄다 (못마땅함)

의미가 중복되는 조사에 주의

포인트 1에서 확인한 しか · ばかり · さえ 중, さえ는 포인트 2에, しか는 포인트 3에 다시 나온다.

→ 한 조사가 여러 의미를 갖는다는 점을 특히 주의할 것.

발음·표기 주의

  • どこでも vs どこででも — "어디서든"의 뉘앙스 차이. 한국어로는 잘 구분하지 않는다
  • どこにでもあります — 어디에나 있습니다

페어 활동에서 나온 예문

  • スポーツは何でもしますが、水泳だけは苦手です (스포츠는 뭐든 하지만 수영만은 못합니다)
    반대로: 水泳だけは誰にも負けません (수영만은 누구에게도 지지 않습니다)
  • 田中さんは学校の食堂へ行くと、ラーメンばかり食べるんです
  • 勉強ばかりしてはいけません / 遊んでばかりではいけません
  • 窓さえ拭けば掃除が終わります / 時間さえあれば旅行に行きたい
  • 田中さんは1日に30回もトイレに行くんです / 5回も歯磨きをするんですか
