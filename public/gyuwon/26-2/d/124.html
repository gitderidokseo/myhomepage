4. 벡 우울척도(BDI) 총점이 24점 이상이면, 그 점수만으로 우울장애를 진단할 수 있다. ( O / X )

6. 2006년 미국 성인 자료에서 정신장애 진단 대상은 약 26%였지만 '행복하다'로 분류된 사람은 약 17%뿐이었다. 이는 "정신장애가 없다고 해서 행복한 것은 아니다"라는 근거가 된다. ( O / X )

7. "감사를 자주 표현하는 사람일수록 더 행복하다"는 상관연구 결과가 있다면, 감사가 행복의 원인이라고 결론 내릴 수 있다. ( O / X )

8. 두 변수 사이의 상관계수가 r = −.25라면, 한 변수가 클수록 다른 변수는 작은 경향이 있다는 뜻일 뿐 인과관계를 알려 주지는 않는다. ( O / X )

9. 자기개념("나는 ○○이다")은 그 자체로 가치판단을 담고 있으므로 자존감과 같은 뜻이다. ( O / X )

10. 자기효능감은 능력에 대한 '믿음'이기 때문에, 근거가 충분하지 않아도 내가 어떻게 생각하느냐에 따라 달라질 수 있다. ( O / X )

11. 자기복잡성이 높은 사람은 한 영역에서 실패해도 다른 영역의 내가 버텨 주기 때문에 정신건강에 유리하다. ( O / X )

12. 수업에서 정의한 성격의 핵심은 일관성이다. 그래서 특정 상황에서만 나타나는 행동은 그 사람의 성격 특징으로 보기 어렵다. ( O / X )

14. 신경성은 행복과 부적 관계에 있으므로 장점이 전혀 없는 특질이다. ( O / X )

삶의 목적 과거·현재의 경험이 모두 의미 있고, 언젠가 삶의 목적을 위해 쓰일 거라는 믿음
환경 통제 (숙달) 나에게 주어진 일을 책임감 있게 해내는 것 (학생: 시험·과제)
(긍정적 대인)관계 따뜻하고 신뢰할 수 있는 관계, 공감·애정, 주고받기(give-and-take)
자율성 스스로 생각·결정·행동. 사회적 압력에 저항, 충동 절제. "지표를 만든다면 꼭 넣을 것"
(개인적) 성장 계속 나아지고 있다고 느끼거나, 나아지려고 삶을 바꾸는 것. "굉장히 중요한 요소"
자기수용 나를 긍정적으로 바라봐 주기 ("나는 내 성격의 거의 모든 면을 좋아한다")

외우는 법: 목·환·관·자·성·수 (삶의 목적, 환경 통제, 관계, 자율성, 성장, 자기수용) 비교: 주관적 안녕감(디너, 1984) = 내가 내 삶을 평가 → 즐거운 삶(수준②) / 심리적 안녕감(리프, 1989) = 덜 주관적, 구체 항목 → 적극적인 삶(수준③) ※ 요소 이름은 수업 녹취에선 "관계·성장", 정리 자료에선 "긍정적 대인관계·개인적 성장"으로 나온다. 둘 다 알아 두기.

② 정신건강 실현의 4수준

수준 내용 측정
① 신체 감각적 활기차고 상쾌한 삶 오감 글쓰기
② 정서적·심리적 즐거운 삶 주관적 안녕감 척도 (디너)
③ 심리적·사회적 적극적인 삶 심리적 안녕감 척도 (리프)
④ 사회적·영적 사회에 기여하는 의미 있는 삶 사회적 안녕감 척도

③ 부적응 판단 4기준 ★ "하나만으로 판단하면 안 된다"

기준 무엇을 보나 누가 판단 한계
통계적 평균에서 벗어났나 (수면 시간, 음주량, IQ 등) 관찰자 평균을 벗어나도 문제 아닐 수 있음 (기발한 사람)
규범적 사회 규범을 따르나 관찰자 시대·문화에 따라 바뀜 (남자 귀걸이 예)
주관적 고통 본인이 "나는 힘들다"고 느끼나 본인 고통 없는 경우도 있음 ("나는 재림 예수다")
역기능적 대인관계·직업에서 잘 기능하나 관찰자 —

적응 = ① 환경에 맞춰 변화 + ② 살아남기 (선인장 가시) 두 모형: 소극적(질병) 모형 = 장애가 없는 상태 / 적극적(성장) 모형 = 장애 없음 + 강점·잠재력 발달 (2006년: 장애 26%, 행복 17%) DSM-5 = 미국정신의학회 진단 편람. 정답이 아니라 계속 수정됨. BDI (벡 우울척도, 21문항): 0~9 우울 아님 / 10~15 가벼운 / 16~23 중간 / 24 이상 심한 → 그래도 단일 척도로 진단 금지

④ 성격 5요인 (Big Five, OCEAN)

성격 = 환경 적응·대인관계에서 일관성 있게 나타나는 행동·사고 양식 MBTI는 유형, Big Five는 모두가 5특질을 갖고 정도만 다름. 형용사를 요인분석으로 묶어 나옴. 점수는 경향성으로 (1~2점 차이 의미 없음).

요인 무엇을 재나 높을 때 특징 (연구) 단점 / 장점
N 신경성 ★ 부정 정서, 스트레스 민감성 덜 행복, 유머 감각↓, 불안·우울장애↑, 이혼↑ 스트레스·우울 ↔ 위험 경계 → 생존 (9·11)
E 외향성 상호작용, 활동 수준, 긍정 정서 더 행복, 인기·데이트↑, 정치적 영향력 원함, 악수 꽉 행복·인기 ↔ 신체적 위험, 가족 안정성
O 개방성 상상력, 예술 감수성, 지적 호기심 미학·철학 관심, 과학 창의성, 진보적, 전통 결혼 평가절하 창의·매력 ↔ 튀어 보임
A 원만성 인간 본성에 대한 낙관, 잘 믿음 감사·용서↑, 결혼 오래 유지, 대인관계 좋음 조화 ↔ 속기 쉬움
C 성실성 책임감·효율, 정리정돈 장수·건강 습관, 정리된 사무실, 교통사고↓ 장기 이득 ↔ 단기 이득 놓침·강박
하위요인 (요인당 6개)
E 따뜻함·군집성·주장성·활동성·자극추구성·긍정정서성
N 불안·적대감·우울·자의식·충동성·스트레스 취약성
A 신뢰성·솔직함·이타성·순응성·겸손함·마음여림
C 유능함·질서정연·책임의식·성취추구·자기절제·신중함
O 상상력·미적추구·감정자각·다양한 활동·지적호기심·가치개방성

웰빙과의 관계: E·A↑ → 주관적 안녕감↑(정적) / N↑ → ↓(부적) / E·C↑, N↓ → 자기수용·환경 통제·삶의 목적↑ 헷갈림 주의: 따뜻함(E) ≠ 이타성(A)

⑤ 셀리그만의 귀인 양식

차원 한쪽 다른 쪽
원인의 위치 외적 (상황·남) 내적 (나)
변화 가능성 불안정적 ("이번에만") 안정적 (늘 그럼)
범위 특정적 ("이 일만") 전반적 ("모든 일")
나쁜 일이 생겼을 때 좋은 일이 생겼을 때
낙관적 외적 · 불안정적 · 특정적 내적 · 안정적 · 전반적
비관적 내적 · 안정적 · 전반적 외적 · 불안정적 · 특정적

한 줄: 낙관적인 사람은 나쁜 일 = "이번에, 이것만, 상황 탓", 좋은 일 = "원래 내가 그래서, 늘". 낙관성은 학습 가능. 단, 행복의 관점에서 낙관이 좋다는 것이고 자기 발전에는 비관적 귀인이 도움이 될 수도 있다.

⑥ ABCDE (셀리그만, 2002)

글자 영어 뜻 예 (카톡 단답)
A Adversity 불행한 사건 좋아하는 사람이 단답
B Belief 왜곡된 신념 "나를 싫어하나 봐"
C Consequence 신념의 결과(감정·행동) 자신감↓, 다가가지 못함
D Disputation 신념 반박 "바빴을 수도 있지"
E Energization 활력 되찾기 다시 힘이 남

반박 4가지 방법: ① 증거 (사실이라는 증거? 반대 증거?) ② 대안 (다른 이유, 특히 외적 요인) ③ 의미·함의 (사실이어도 그게 무슨 뜻? 확대 해석 아닌가?) ④ 유용성 (이 생각이 나에게 도움이 되나?) 교수님 강조: "이것밖에 답이 없다"와 "여러 대안 중 이게 확률이 높다"는 완전히 다르다 → 대안이 있다는 것 자체가 중요.

⑦ 자기(self) 관련 개념

개념 뜻 꼭 기억할 점
자기개념 나에 대한 나의 정의 ("나는 ___이다") 가치중립일 수 있음. 형성 요인: 자기 행동 관찰·사회적 비교·타인의 피드백·문화적 기대
자존감 (self-esteem) 자기개념의 평가적 차원 (가치 판단 + 감정) 로젠버그 척도. 영향 요인: 연령(어릴 때 최고), 양육(안정애착), 사회비교(친구의 성공이 더 위협), 문화(아시아는 겸손 → 점수↓), SES
자기효능감 (self-efficacy) 특정 과제를 잘 해낼 수 있다는 믿음 (반두라) 4요인: 성취 경험 · 대리 경험(대학생 시기에 가장 중요) · 언어적 격려(어릴수록 영향↑) · 정서·신체 상태
자기수용 (self-acceptance) 나를 있는 그대로 받아 주기 (MacInnes, 2006) 무조건적 자기수용: 잘하든 못하든, 남이 인정하든 말든 수용. "받아 줄 때 변화가 시작된다". 리프 6요소 중 하나
자기복잡성 (self-complexity) 나를 얼마나 다양하고 구분되는 측면으로 이해하나 (린빌, 1985) 높을수록 유리 (정서적 완충). "복잡한 성격"이 아님. 비슷한 생각: 히라노 게이치로의 분인
SES 사회경제적 지위 "꼭 알고 수업을 마쳐야 할 용어". 연구에서 통제해야 함

⑧ 연구 방법 · 관계 (덤)

개념 핵심
상관 ≠ 인과 감사와 행복, 손주 돌봄과 조부모 건강 → 순서를 모름
실험 독립변인(원인, 예: 감사일기) / 종속변인(결과, 예: 행복) / 실험집단·통제집단
