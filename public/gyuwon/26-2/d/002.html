7. 과목별 핵심내용 한 장 요약

일본어표현연습 (월) — 조사 포인트 2·3·4

  • 포인트 2 だけ(한정) / こそ(강조) / 〜てまで(극단적 수단) / さえ(~조차)
  • 포인트 3 しか〜ない / でも(가벼운 제안) / なんて(놀람) / ぐらい(최소한)
  • 포인트 4 ★ 나열 표현 やら / とか / だの / にしても — 「だの」만 마이너스(불평·변명) 뉘앙스
  • 헷갈리지 말 것: 「〜さえ」(~조차) ≠ 「〜さえ〜ば」(~만 있으면) / 「なんて」(놀람) ≠ 「なんか」(경시)

일본어표현연습 (수) — しか 복습 + 음식점·카페

  • 「しか」 구분법 — 숫자가 들어가면 "적다"(5時間しか寝ていない), 없으면 "그것뿐"(これしかない)
  • 「だの」 마이너스 재강조 — 문장은 맞지만 직장에서 쓰면 이상하게 보일 수 있다
  • 점원: すみません / お待たせしました / 少々お待ちください / かしこまりました / 確認してまいります
  • 손님 핵심 2문장: 「あとどれくらいかかりますか」 / 「注文したものと違うものが来たようです」
  • 복합동사 〜直す (作り直す = もう一度作る를 한 단어로)
  • ★ そうです 두 종류 — 마스형+そう = 양태(~할 것 같다) / 기본형+そう = 전문(~라고 한다)

정신건강과 자기돌봄 — 정신건강의 원인 + 자기이해

  • 원인 4관점: 생물학 / 심리 / 사회 / (영성) + 통합한 생물–심리–사회 모형
  • 상관 ≠ 인과. 감사 연구가 상관연구 → 실험연구로 넘어간 과정이 교과서적 예시
  • 감사일기는 주 1회. 주 3회는 숙제가 되어 효과가 사라짐
  • 자기개념(중립) → 자존감(평가) 구분이 핵심. 로젠버그 척도 10문항
  • 자기효능감(반두라) 4요인 중 지금 나이대엔 대리 경험이 가장 강력
  • 자기복잡성(린빌) — 높을수록 한 영역의 실패가 전체를 무너뜨리지 않음(정서적 완충). 히라노 게이치로의 '분인(分人)' → 이번 주 과제 주제

종교와 사회복지 — 오리엔테이션

  • 방법론: "뭉치면 죽고 쪼개면 산다" — 해체해서 보기
  • 종교 = religio = re(다시) + ligare(연결하다) → 인간↔신, 인간↔인간, 인간↔세계를 다시 잇는 것
  • 실체는 없고 정체만 있다 — 모든 것이 연결되어 있어 독립된 실체가 없다
  • 표층 종교(문자주의·이기적) → 심층 종교(문자 너머·참나)
  • 사회복지 = Social + Well + Fare = 사회적으로 잘 살아가는 것
  • ★ 커뮤니언(Communion)이 종교 사회복지의 원천. 종교와 사회복지는 한 바다 위의 두 파도
  • 복지모델 3단계 — 의존(받는 복지, ~1980s) → 자립(생산적 복지, 1990s) → 상호의존(커뮤니티 케어, 2018~). 자립시켰더니 고립되어서 나온 것이 3단계
  • 마지막 당부: "내 뜻대로 안 되는 것이 정상이다"

노인복지론 — 3장 복습 + 사례 개입 실습

  • 수업의 절반 이상이 최영자 씨 사례 개입계획 조별활동 — "왜 그렇게 결정했는지 이유를 말할 수 있어야 한다"
  • 대부분의 조가 주거환경 개선을 1순위로. 판단 기준: 시급성 / 실현 가능성 / 지속 가능성 / 효율성 / 당사자의 선택
  • 의료 / 비의료의 경계는 흐릿하고, 그 흐릿한 지점이 사회복지사가 실제로 일하는 자리

일본기업론 — 재벌 해체 → 게이레츠 → 메인뱅크

  • 1989년 세계 시총 상위 20개 중 일본 14개 → 2026년 0개
  • PBR — 1 미만이 무조건 좋은 게 아니고 1 이상이 무조건 나쁜 것도 아니다. 정보의 비대칭 때문에 어떤 기업도 완전히 평가할 수 없다
  • 버블 = 플라자 합의(엔고) + 저금리 + 100% 주택담보대출 / 붕괴 = 금리 인상 + 대출 총량 규제
  • 장기 침체의 이유 — 번 돈이 전부 빚 갚는 데 쓰여 경제 순환에 들어가지 않았다
  • GHQ 재벌 해체(1946~47) → 독금법 완화(1953) → 은행·종합상사 중심의 '주인 없는 그룹' = 게이레츠
  • 게이레츠의 두 얼굴 — 기업 간에는 수평(상호주식보유), 하청 관계에서는 수직
  • 메인뱅크 3역할 — 자금 공급 / 경영 감시 / 위기 시 구제
  • 15주 내내 가져갈 질문: "일본 기업 시스템은 정체인가, 재편인가"

스피치의 이해 — 스피치 구조 (영화 제작 비유)

  • 초반 30초가 전부 — 근거는 인지적 구두쇠(초반 정보가 남고 나중 정보는 밀려남)
  • SMART로 설계 / 시나리오(쓰는 것) ≠ 콘티(보여주는 것)
  • 형용사·부사가 강세를 훔친다. 남는 건 동사와 데이터
  • 다섯 글자로 줄이기 — 리영희 교수의 훈련법
  • 청킹 — 네다섯 개의 기억 묶음(=시퀀스)이 한 편의 스피치를 완성
  • 변화가 없으면 아무도 기억하지 않는다 — 변곡점·반전·3초 멈춤
  • 완벽함은 방어기제를 만든다. 가장 사적인 고백이 가장 보편적인 설득력을 얻는다
  • ★ 마침표는 화자가 아닌 청중이 찍는다 — "이번 학기는 이거 하나만 기억하면 됩니다"
