수업 방식 거의 모든 문법 포인트를 페어(짝) 연습으로 작문 → 발표 → 교사 코멘트

포인트 2 — だけ / こそ / まで / さえ

① 〜だけ — 한정

앞 시간에 원형만 확인했고, 이날은 접속 형태별 작문 연습을 했다.

접속 예 교사 코멘트
な형용사 + なだけ 好きなだけ "な형용사 + だけ는 별로 안 씁니다." 「好きなだけ」 정도. 「満足なだけ」 같은 건 거의 말하지 않는다
い형용사 + だけ いいだけ
동사 + だけ 欲しいだけ / 食べたいだけ 자연스러운 쪽

정리 — 「好きなだけ」「欲しいだけ」「食べたいだけ」처럼 희망·기호 표현과 붙는 형태가 자연스럽다.

② 〜こそ — 강조

예문 뜻
今年こそ 올해야말로
こちらこそ 저야말로 (자기소개 인사 「よろしくお願いします」에 대한 답)
〜するからこそ ~하기 때문에야말로

페어 연습 — 「今年こそ ___」

학생들이 만든 목표들:

일본어 뜻
今年こそ 早く起きる 일찍 일어나기
今年こそ お金を稼ぐ / 貯金する 돈 벌기 / 저축하기
今年こそ 世界旅行する 세계여행
今年こそ 禁煙する 금연
今年こそ ダイエットする 다이어트
今年こそ 車を買う / 引っ越す 차 사기 / 이사
今年こそ JLPT に合格する JLPT 합격 (가장 많이 나온 답)

교사 코멘트 — 「今年こそ」는 꽤 강한 말투라서, "여러분 목표에 비하면 좀 오버인 것도 있네요" (웃음). 그만큼 강한 결의를 담는 표현.

③ 〜てまで / 〜まで — 극단적인 수단 ★

포인트 — 동사 て형 + まで = "~해서까지". 거기까지 할 필요는 없다는 뉘앙스로 자주 쓴다.

예문 뜻
予約までして行かなくてもいいですよ 예약까지 해서 갈 필요는 없어요
会社を休んでまで行く 회사를 쉬면서까지 가다
無理してまで行かなくてもいい 무리해서까지 갈 필요는 없다
タクシーを予約してまで 택시를 예약해서까지
学校を休んでまでして行かなくていい 학교를 쉬면서까지 갈 필요는 없다

교사가 든 실제 사례 — 1~2년 전 교환학생이 만든 문장: 「学校を休んでまでして行かなくていい」 → "도대체 어떤 레스토랑인데?" (인기가 많으니까 그렇겠지 하는 상상력). "좋았어요."

활용 팁 — 애니메이션이나 드라마에서 「〜までしなくていいよ」 같은 형태로 자주 접했을 표현. 가장 많이 나오는 조합은 「予약(예약)」. 그 밖에 化粧してまで / おしゃれしてまで 같은 것도 가능하다.

④ 〜さえ — ~조차

주의 — 앞 단원에서 배운 「〜さえ〜ば」(あなたさえいれば / 時間さえあれば)와 의미가 다르다. 여기서는 "~조차".

페어 연습 — 「最近は3歳の子供さえ ___」

일본어 뜻
最近は3歳の子供さえ スマホが使える 요즘은 세 살 아이조차 스마트폰을 쓴다
最近は3歳の子供さえ 英語ができる 세 살 아이조차 영어를 한다
最近は3歳の子供さえ AI が使える 세 살 아이조차 AI를 쓴다 ★
子供さえ知っている 아이조차 알고 있다

교사 반응 — "AI가 사용 가능한 세 살, 대단하네요." / 학생들이 사교육(塾)·주식 등 다양한 의견을 냄

포인트 3 — しか / でも / なんて / ぐらい

① 〜しか〜ない — ~밖에 없다 / ~할 수밖에 없다

예문 뜻
やるしかない / 行くしかない / 食べるしかない 할 수밖에 / 갈 수밖에 / 먹을 수밖에 없다
まだ私しか来ていません 아직 저밖에 안 왔어요
一人しか来ていません / 二人しか来ていません 한 명/두 명밖에 안 왔어요

연습 문제 B — 「まだ ___ しか来ていません」 → 私たち / 子供 / 君 / ○○さん 등. "적다"는 뜻이니 두 명이어도 괜찮습니다.

② 〜でも — 가벼운 제안

예문 뜻
お茶でも飲みませんか / お茶でも飲みましょうか 차라도 마시지 않을래요?
ご飯でも食べましょうか 밥이라도 먹을까요?
歌でも歌いましょうか 노래라도 부를까요?

「お茶でも飲みましょうか」가 압도적으로 많이 나온 답.

③ 〜なんて — 놀람 · 의외 · 경시

예문 뜻
田中さんが学校を休むなんて驚きました 다나카 씨가 학교를 쉬다니 놀랐어요
ご飯を食べないなんて、どうしましたか 밥을 안 먹다니 무슨 일이에요?
テストなんかなければいいのに 시험 따위 없으면 좋을 텐데
学校なんかなければ 학교 따위 없으면

교사 주의 — 「田中さんが学校を休むなんか」는 별로 말하지 않는다. 놀람에는 なんて. 「なんか」는 가벼운 경시·예시로 쓰인다 (테스트·학교 예문 쪽). 학생들이 만든 「テストなんかなければいいのに」에 교사 반응 — "3번은 지금 딱 그런 기분이네요." (웃음)

④ 〜ぐらい — 최소한 그 정도는

「小学生なんだから _ ぐらい _ でしょう」 형태로 연습

예문 뜻
漢字ぐらいできるでしょ 한자 정도는 할 수 있잖아
歯磨きぐらい自分でできるでしょう 양치 정도는 혼자 할 수 있잖아
部屋の片付けぐらいできるでしょう 방 정리 정도는 할 수 있잖아
お皿洗いぐらいできるでしょう 설거지 정도는 할 수 있잖아
自分の部屋の掃除ぐらいできるでしょう 자기 방 청소 정도는 할 수 있잖아
一人で乗れるでしょう 혼자 탈 수 있잖아

교사 코멘트 — 「小学生なんだから」로 시작하는 문형이 아주 좋았다. "한자 할 수 있는 초등학생 대단하네요." 다만 "혼자 (버스를) 탈 수 있잖아"는 "어, 근데 위험한가? 초등학생인데." — 예문의 현실성도 함께 검토.

포인트 4 — 나열 표현: やら / とか / だの / にしても ★

오늘 가장 중요한 포인트. 한국어로 옮기면 넷 다 비슷하게 "~며, ~라든지, ~든"이 되기 때문에 차이를 구분해야 한다.

★ 핵심 — だの는 마이너스 뉘앙스

「だの」에는 부정적인(マイナスの) 의미가 있다. 불평·변명·짜증을 늘어놓는 상황에서 쓴다.

표현 뉘앙스 예문
〜や〜(など) 중립적 나열 机の上にペンやノートなどがあります (책상 위에 펜이랑 노트 등이 있습니다)
〜やら〜やら 중립 · 뒤섞여 있는 느낌 赤やら黄色やら、いろんな色の花が咲いている (빨강이며 노랑이며 여러 색의 꽃이 피어 있다) / キムチやらカレーやら、辛いものが好きです
〜とか〜とか 가벼운 예시 スキーとかスケートとか、冬のスポーツが好きです
〜だの〜だの ★ 마이너스 · 불평 眠いだの疲れただの言わないで、早く宿題をしなさいよ (졸리다느니 피곤하다느니 하지 말고 빨리 숙제해) / 行くだの帰るだの
〜にしても〜にしても ~하든 ~하든 山に行くにしても海に行くにしても、いつもキムさんと一緒です

교사 강조 — 「だの」는 감정이 들어가는 표현. 변명할 때나 불평을 늘어놓을 때 쓰인다. "마이너스 이미지가 있다"는 점을 반드시 기억할 것. 한국어로는 「〜라느니 〜라느니」, 「〜며 〜며」, 「〜든 〜든」 등으로 옮겨지지만 뉘앙스가 다르다.

마무리 — 포인트 1~4 통합 확인 프린트 (1~16번)

구간 대응 포인트
1 ~ 9번 포인트 1 · 2 (だけ / こそ / まで / さえ 등)
10 ~ 16번 포인트 3 · 4 (しか / でも / なんて / ぐらい / やら / とか / だの / にしても)

진행 방식

  1. 개인으로 5~6분 풀기 — 보면서 써도 되고, 안 보고 써도 되고, 찾아보면서 써도 됨
  2. 페어로 확인 — 한국어 번역을 대조하며 1번부터 16번까지 읽으며 확인
  3. 교사 코멘트

교사: "JLPT를 푸는 것 같은 시간이네요. 머리 아프죠? 힘내세요."

교사가 짚어준 항목

번호 내용
3번 답이 여러 개 가능 — だけ / まで / でも 등을 쓴 학생이 각각 있었고 모두 틀린 것이 아님. 예: 「パソコンまで準備したから」(이것까지 준비했다는 의미로 OK), 「だけ」도 가능
9번 「子供でも知っている」 / 「子供さえ知っている」 / 「子供こそ」 등 여러 답이 논의됨
12번 근처 「ぐらいしか」 형태 — 「少しだけ」 vs 「少ししか」 구분
15 · 16번 가장 어려움. 16번은 「ゴミ」와 「空間」을 플러스로 보느냐 마이너스로 보느냐에 따라 답이 달라진다
전반 두 가지 답이 모두 가능한 문항이 한두 개 있다

이 수업에서 남길 것

  1. 「な형용사 + だけ」는 거의 안 쓴다. 「好きなだけ」 정도
  2. 「今年こそ」는 강한 결의. 가벼운 목표에 쓰면 오버가 된다
  3. 「〜てまで」는 극단적 수단 — "거기까지 할 필요는 없다"는 맥락에서 가장 자주 쓰인다
  4. 「〜さえ」(~조차) ≠ 「〜さえ〜ば」(~만 있으면). 앞 단원과 헷갈리지 말 것
  5. 「なんて」는 놀람, 「なんか」는 경시. 「休むなんか」라고는 잘 안 한다
  6. 「ぐらい」는 최소한. 「小学生なんだから漢字ぐらい」 패턴으로 통째로 기억
  7. ★ 「だの」는 마이너스. 나열 표현 네 개 중 이것만 감정(불평·변명)이 들어간다
  8. 조사는 두 파트로 나뉜다. 이번이 ①, 나중에 ②가 또 온다 — N2 수준 조사가 많다

전사가 불명확했던 항목

항목 상태
확인 프린트 1~16번 전체 문항 복원 불가. 프린트 원본을 반드시 확인할 것 — 시험 범위
15·16번의 정확한 문장 전사 불가. 16번은 「ゴミ」「空間」이 포함된 문장이라는 단서만 있음
교재 포인트 1의 내용 지난 시간 분량이라 이 전사본에 없음
예문의 정확한 표기·조사 위 예문은 표준형으로 복원한 것. 교재 원문과 대조 필요
