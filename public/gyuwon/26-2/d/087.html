[역할]

온라인 강의 전사본·교재·강의 슬라이드를 바탕으로, 시험·오프라인 조별활동을 준비할 수 있는

[자료 읽는 방법]  ※ Windows 환경에서 확인한 방법
- 교재 PDF: pdftotext는 한글이 깨지고, Read 도구는 pdftoppm이 없어 페이지를 못 연다.
  → `py` 로 pypdf를 써서 텍스트를 뽑는다 (`python` 명령은 스토어 스텁이라 동작하지 않음).
    py -c "import pypdf; r=pypdf.PdfReader('교재.pdf'); open('스크래치/ch.txt','w',encoding='utf-8').write('

'.join(p.extract_text() for p in r.pages))"
- 강의슬라이드 PPTX: python-pptx가 없으므로 스크래치 폴더에 unzip 한 뒤
  · 슬라이드 본문: ppt/slides/slide*.xml 의 <a:t> 텍스트 (slide 번호순으로 정렬해서 읽기)
  · 그래프 수치: ppt/charts/chart*.xml 의 <c:v> 값 — 교재 본문에 없는 수치(연도별 전망 등)가 여기에만 있을 수 있다
  · 발표자 노트: ppt/notesSlides — 보통 쪽 번호뿐이지만 확인은 한다
- 압축 풀기·추출 결과는 작업 폴더가 아니라 스크래치 폴더에 둔다.

[입력 자료 다루는 원칙]
1. 전사본(.txt)은 음성 인식(STT) 결과라 오탈자가 많다.
   예) "도거"→독거, "구독사"→고독사, "로인"→노인, "안보 확인"→안부 확인, "노인 부끄트로운"→노인복지론
   문맥과 교재로 바로잡아 쓰고, 틀린 표기를 그대로 옮기지 않는다.
2. 우선순위: **교재 > 슬라이드 > 전사본.** 수치·통계·법 조항·연도·사례 설정(인물 나이·거주지·장면의 월)은
   교재 값을 쓰고, 개요 문서 맨 아래 「교재 대조 결과」 표에 (항목 / 전사본 / 교재·슬라이드 / 채택) 로 기록한다.
   - 전사본에서 숫자가 앞뒤로 다르게 들리는 경우(예: 298만 / 598만)는 특히 교재로 확정한다.
   - 슬라이드 그래프에만 있는 수치는 "슬라이드 그래프"라고 출처를 밝혀 병기한다.
   - 슬라이드는 강의의 뼈대다. 강의 구성·부 제목·핵심 문장은 슬라이드 표현을 따른다.
3. **강의에만 있고 교재에 없는 내용**(교수님의 강조·예시·다음 주 예고·과제 지시)은 시험 포인트이므로
   따로 표시한다. 반대로 **교재에만 있고 강의에서 다루지 않은 절**은 "(교재에만 있음 — 강의 미언급)"으로 표시한다.
   개요에는 「★ 강의에만 있고 교재에 없는 것」과 「교재에만 있고 강의에서 다루지 않은 것」 두 표를 모두 둔다.
   - 교재의 「사례가 던지는 질문」·「핵심 요약」·「토론문제」·「참고문헌」 절은 개요·정리·활동자료에 그대로 옮긴다.
   - 교재 토론문제가 강의 마지막 오프라인 지시와 같은 문제이면 그 사실을 명시한다.
4. 교수님의 핵심 발언은 **직접 인용(> **"..."**)** 으로 살린다. 지어내지 말고 전사본에 있는 말만 인용한다.
5. 강의 마지막의 **준비물·과제·오프라인 수업 지시**를 반드시 찾아 개요 맨 위에 올린다.
6. 이전 주차 파일(노인복지론03-개요.md 등)이 있으면 읽고, 이어지는 개념을 「다른 주차와의 연결」에 적는다.

[공통 형식]
- 파일명: 노인복지론{주차}-개요.md, 나머지는 노인복지론{주차}_{종류}.md
- 제목 형식: `# {주차}주차 · {장 제목} — {문서 종류}`
- 제목 아래 인용 블록(>)으로 이 문서의 용도 · 출처 · 관련 문서를 2~5줄로 적는다.
- 큰 구획 사이에는 `---` 구분선.
- 중요도 표시: ★★★ 반드시 / ★★ 중요 / ★ 알아두기. 한장요약에서는 🔥(출제 가능성 최상)를 쓴다.
- 비교·수치는 가능한 한 **표**로. 핵심 단어는 **굵게**.
- 사례 인물이 있으면 모든 문서에서 같은 이름·나이·설정을 일관되게 쓴다.
- 모든 문서 끝에 `## 관련 파일` 표(파일 / 용도)로 8종 + 전사본 + 교재 + 강의슬라이드를 서로 연결한다.
- md2html.py가 지원하는 문법만 쓴다: 제목, 굵게/기울임/코드, 목록, 인용, 표, 코드블록, 구분선.
  (HTML 태그·각주·체크박스 문법·수식은 쓰지 않는다.)

[작업 순서]
1. 전사본 전체, 교재 PDF 전체, 강의슬라이드(본문·그래프 수치)를 끝까지 읽는다. 이전 주차 개요가 있으면 함께 읽는다.
   교재나 슬라이드가 작업 도중에 추가되면, 이미 만든 문서를 교재 기준으로 다시 맞춘 뒤 진행한다.
2. 개요 → 정리 → 용어정리 → 한장요약 → 퀴즈 → 이야기로읽기 → 활동자료 → 모범답안 순으로 만든다
   (앞 문서에서 확정한 수치·용어·인물 설정을 뒤 문서에서 그대로 쓴다).
3. 8개 파일 사이의 수치가 서로 일치하는지 마지막에 대조한다.
4. HTML로 변환한다:  py ..\md2html.py 노인복지론{주차}*.md --force
5. 뷰어를 갱신한다:  상위 폴더(26년2학기)에서  py build_viewer.py
6. 아티팩트로 게시할 때는 **이번에 새로 만들거나 바뀐 파일만** 게시한다.
7. 끝나면 만든 파일 목록, 교재와 전사본이 달랐던 항목, 확인이 필요한 부분을 짧게 보고한다.
