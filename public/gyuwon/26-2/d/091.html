1. 인지 노화의 기본 개념 ★★★

용어 영문 정의 중요도
인지 cognition 단일한 능력이 아니라 여러 하위 기능의 묶음. 노화에 따른 변화 양상이 영역마다 다르다 ★★★
정보처리 속도 processing speed 같은 과제를 수행하는 데 걸리는 시간. 노년기에 저하 ★★
작업기억 working memory 여러 정보를 동시에 머릿속에 붙들고 조작하는 능력. 저하 ★★
부호화와 인출 encoding / retrieval 새 정보를 저장하고 꺼내는 일. 저하. 이름이 안 떠오르는 것은 인출의 문제 — 매우 흔함 ★★
선택적 주의와 억제 기능 selective attention / inhibition 소음 속에서 한 사람의 말에 집중하는 능력. 저하 ★★
어휘력과 일반 지식 vocabulary / general knowledge 대체로 유지 ★★
절차적 기술 procedural skill 오래 반복해 온 기술(자전거 타기, 익숙한 조리 과정). 잘 남는다 ★★★
정서 조절과 사회적 판단 emotion regulation / social judgment 경험의 축적으로 오히려 향상될 수 있다 ★★
원거리 기억 remote memory 오래전 일의 기억. 한 씨가 젊은 시절 이야기를 세세히 기억하는 것 — 보존 ★

2. 판별과 감별 ★★★

용어 정의 중요도
판별 3질문 ① 일상생활 기능에 영향을 주는가 ② 익숙한 일에서 문제가 생기는가 ③ 잊었다는 사실 자체를 인식하는가 ★★★
판별 ≠ 진단 (강의) 사회복지사의 판단은 정상인지 아닌지를 결론짓는 것이 아니라 확인이 필요한 상태인지 아닌지를 가르는 것 ★★★
"노화는 느리게 진행된다" 3장의 원칙. 최근 몇 달 사이에 뚜렷한 변화는 노화가 아닐 가능성이 높다 ★★
감별 (다른 원인들) 치매와 유사한 인지 저하를 만들면서 원인을 제거하면 상당히 회복되는 요인들: 우울 · 약물 · 감각 손실 · 신체 질환·급성 상태 ★★★
다약제 복용 polypharmacy. 여러 약을 함께 복용 + 노년기 약물 대사 변화 → 인지에 영향 (3장) ★★
섬망 delirium. 입원 중 갑작스러운 혼동 등 — 치매와 구분되는 급성 상태. 원인 치료 필요 ★★
"나이 들면 다 그래" 남편의 말. 위험한 이유 — 확인을 중단시키기 때문 (3주차와 같은 오류) ★★★

감별 4원인과 확인 질문 (강의)

원인 확인 질문
우울 "요즘 기분은 어떠세요?" (최근 상실 경험)
약물 "약이 바뀌셨어요?"
감각 손실 "보청기 쓰세요?" (청력 변화)
신체 질환·급성 상태 "최근에 아프셨어요?"

"이 네 가지만 물어도 상당 부분은 걸러진다." — 이 확인은 진단을 대신하는 것이 아니라 진단으로 가는 과정에서 필요한 정보를 모으는 일

3. 경도인지장애 ★★★

용어 영문 정의 중요도
경도인지장애 mild cognitive impairment (MCI) 기억력, 언어능력, 지남력 등 객관적인 검사에서 확인될 정도로 저하되어 있으나 일상생활을 수행하는 능력은 보존되어 있어 치매가 아닌 상태 (보건복지부, 2025) ★★★
지남력 orientation 시간·장소·사람을 알아보는 능력. 정의 속 저하 영역의 하나 ★
주관적 호소 subjective complaint "요즘 깜빡깜빡해" — 객관적 검사로 확인되지 않은 불편. 경도인지장애와 구분 ★★
전환율 conversion rate 경도인지장애 → 치매 연 10~15% / 정상군 1~2% (Petersen et al., 2001) ★★★
정상 회복 reversion 조기 개입·관리 시 약 30% — 저절로가 아니라 개입했을 때 ★★★
개입의 창 window of opportunity 치매로 진행한 뒤엔 되돌리기 어렵지만, 이 단계에서는 위험요인 관리와 인지 활동으로 진행을 늦출 여지가 있다 ★★★
인지강화교실 — 치매안심센터의 경도인지장애 대상 프로그램. 주 1회 → 주 3회 확충 계획 ★★

꼭 붙여서 외울 것

경계 ① 주관적 호소 ↔ 경도인지장애 = "객관적 검사에서 확인되는가" 경계 ② 경도인지장애 ↔ 치매 = "일상생활 수행능력이 보존되는가"

두 숫자는 함께 읽는다 — 10~15%(위험 신호) + 30%(개입의 여지). 한쪽만 읽으면 '치매 예고'(낙담) 또는 "괜찮다"(방치)

경도인지장애 = 인지 + 낙상 위험(균형·보행) + 우울감 — 하나의 문제만 보지 말 것

4. 치매와 통계 용어 ★★★

용어 영문 정의 중요도
치매 dementia 특정 질병의 이름이 아니라, 여러 원인 질환에 의해 인지 기능이 저하되어 일상생활에 지장이 생긴 상태를 가리키는 임상적 증후군 ★★★
임상적 증후군 clinical syndrome 원인이 아니라 나타나는 상태로 묶은 개념 ★★
혈관성 치매 vascular dementia 원인 질환 중 하나. 혈압과 혈당 관리가 진행에 영향을 줄 수 있다 ★★
알츠하이머병 Alzheimer's disease 원인 질환 중 하나. 치매 = 알츠하이머가 아니다 ★★
치매 사망 집계 — 2024 사망원인통계: 혈관성 치매 + 상세불명의 치매 + 알츠하이머병 합산 ★★
유병률 prevalence 환자 수(분자) ÷ 인구(분모). 분모가 더 빨리 커지면 환자가 늘어도 떨어진다 ★★★
분모 효과 — 1차 베이비붐 세대 진입으로 65세 이상 인구 약 268만 명 증가 → 치매 유병률 9.50→9.25% ★★★
1차 베이비붐 세대 — 1955~1963년생. 2020년부터 1955년생이 65세 진입 ★★
치매역학조사 — 「치매관리법」 제14조 근거. 2008·2012·2016·2023 (네 번째, 7년 만) ★★
선별검사 vs 진단 screening / diagnosis 선별의 '인지저하'(노인실태조사 24.6%)와 진단된 '치매'(9.25%)는 다른 것을 잰다 ★★★
K-MMSE~2 — 2023 노인실태조사에서 인지기능을 직접 측정한 도구(표준형) ★

5. 위험요인과 예방 ★★★

용어 영문 정의 중요도
수정 가능한 위험요인 modifiable risk factors 관리·교정으로 바꿀 수 있는 위험요인. 란셋 2024 — 14개 ★★★
란셋 위원회 보고서 Lancet Commission (Livingston et al., 2024) 14개 요인 관리 시 치매 발병의 약 45% 예방 가능 ★★★
인구기여위험분율 population attributable fraction (PAF) 해당 요인이 없어지면 줄어드는 발병의 비율. 청력 손실·고콜레스테롤증 각 7% 최대 ★★
생애 전 단계의 과제 life-course approach 45세 이전 교육, 중년기 건강이 노년기 인지를 좌우 → 치매 예방은 노인복지 + 생애 전 단계의 과제 ★★★
예방의 도구 / 비난의 도구 — 요인 대부분이 사회적 조건에 달려 있다. "관리하지 않은 개인의 탓"으로 옮기는 순간 비난의 도구 ★★★
치매예방수칙 3-3-3 — 2016년 개발 후 미개정 → 14개 위험인자에 맞게 개편, 치매체크앱으로 배포 예정 ★★

7. 실천 용어 ★★

용어 정의 중요도
"무엇을 잊는지" 묻기 (강의) 가족 호소를 들을 때 구체적으로 물을 것 — 이름(인출, 흔함) vs 어제 식사를 아예 모름(다름) ★★
