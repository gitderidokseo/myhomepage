일본어 표현연습 (수) 3주차 — しか 복습 + 場面に合う表現 ②: 음식점·카페 (정리)

출처 일본어 표현연습 0916 (수).txt / 음성 일본어 표현연습 0916 (수).m4a 일시·장소 2026-09-16(수) 15:00–16:15 · 새천년관 7304 구성 ① 월요일 조사 단원 복습(しか의 의미 구분, 나열 표현) → ② 場面に合う表現 두 번째 — 레스토랑·카페 장면 → ③ そうです 두 종류 + 번역 연습 1~10번

⚠ 전사 품질 주의 — 이 파일은 3주차 전사본 중 품질이 가장 나쁩니다(한국어·일본어가 뒤섞여 인식). 아래 예문은 맥락으로 복원한 표준형이며, 반드시 교재·프린트로 확인하세요.

공지

항목 내용
과제 공지 없었음
오늘의 성격 월요일 문법(조사)의 애매했던 지점을 교사가 스스로 정정·보충하고, 새 단원(장면별 표현)으로 진행
교사의 사과 「しか」 예문이 애매했다며 본인이 만든 예문에 문제가 있었다고 인정하고 다시 설명

1부 — 복습 ①: 〜しか의 세 가지 의미 구분 ★

교사: "「しか」에 세 가지 의미가 있어서 어느 쪽인지 헷갈리는데, 저도 여기 しか와 저기 しか의 명확한 차이를 못 느껴서 제가 만든 예문에 문제가 있었던 것 같아요. 그래서 지금 다시 말씀드릴게요."

포인트 의미 판별 기준 예
포인트 1 "~밖에 없다" — 다른 것은 없다 대상이 딱 하나로 한정될 때 これしかありません (이것밖에 없습니다) / 一人しか来ません
포인트 3(5번) "적다"는 느낌 숫자가 들어갈 때 5時間しか寝ていない (5시간밖에 못 잤다) / 40分しか〜ない / 学校まで10分しかかからない

핵심 판별법 — 숫자가 들어가면 "적다"는 느낌을 주는 쪽. 「これしかない」는 "이것 말고는 없다"(포인트 1)이고, 「5時間しか寝ていない」는 "1분도 없다"는 게 아니라 "딱 그만큼뿐이라 적다"는 뜻(포인트 3).

복습 ② — 나열 표현 네 개 (월요일 포인트 4)

「〜や〜」 / 「〜たり〜たり」 / 「〜だの〜だの」 / 「〜にしても〜にしても」

교사가 다시 강조한 것:

「だの」에는 마이너스 의미가 있으므로 말을 더 조심해야 한다. 사용에 유의할 것. 다만 절대 쓰면 안 되는 것은 아니다. 문장 자체는 맞는 문장이다. 회사(직장)에 가면 너무 이상하게 보일 수 있다는 점만 알아둘 것.

"이 부분 꼭 유의하세요" — 월요일에 이어 두 번 강조된 지점.

2부 — 場面に合う表現 ② : 음식점 · 카페 ★★

오늘의 새 단원. "이런 상황이라면 일본어로 어떻게 말하면 자연스러울까"를 익히는 파트. 교사의 접근법 — "한국어로 생각하면 쉬울 것 같습니다. 한국어로는 이렇게 말하죠? 그러면 일본어로는 어떻게 말할까요?"

다루는 두 가지 상황

# 상황
① 주문한 음식이 안 나올 때 — 어떻게 말합니까?
② 주문과 다른 것이 나왔을 때 — "이거 주문한 거 아닌데요"를 어떻게 말합니까?

워밍업 — 한국어 사례 공유

먼저 학생들의 실제 경험을 한국어로 나눔:

  • 웨이팅이 많은 피자집에서 거의 한 시간 기다린 경험
  • "얼마나 더 기다려야 될까요?", "얼마나 더 걸리나요?"라고 물어본다
  • 샐러드 하나가 한 시간 걸린 경우, 주문을 취소하기도 한다
  • 학교 식당은 수업 끝나는 시간에 가면 많이 밀린다

롤플레이 — A(손님) / B(점원)

프린트의 1~10번 표현을 상황에 맞춰 골라 쓰는 연습. 자리(레스토랑 / 카페)에 따라 말투가 달라진다는 것이 핵심.

카페 vs 레스토랑

상황 표현
카페 — 주문 アイスアメリカーノ처럼 메뉴 이름만 말해도 통한다 (친구에게 하듯 가볍게)
레스토랑 — 점원 주문 확인 후 "조금만 기다려 주세요" → 少々お待ちください

상황별 표현 정리 (복원)

상황 표현 뜻
부를 때 すみません 저기요
기다리게 했을 때 お待たせしました 오래 기다리셨습니다
기다려 달라고 할 때 少々お待ちください 잠시만 기다려 주십시오
주문을 받았을 때 かしこまりました 알겠습니다
확인하러 갈 때 確認してまいります 확인하고 오겠습니다
음식이 늦을 때 (손님) あとどれくらいかかりますか 앞으로 얼마나 걸리나요?
다른 게 나왔을 때 (손님) 注文したものと違うものが来たようです 주문한 것과 다른 게 나온 것 같아요
순서가 밀렸을 때 (손님) 私より後に注文した人が… 저보다 나중에 주문한 사람이…
사과 (점원) 申し訳ございません / すぐにお持ちします 죄송합니다 / 바로 가져다 드리겠습니다
서비스 제공 コーラをサービスで 콜라를 서비스로

교사 코멘트 — "나중에 나오는 표현이 하나가 아니지만, 이런 표현을 많이 씁니다." 1·8번은 「すみません」 정도가 될 것이고, 2·3·6번이 이런 상황에 가장 많이 쓰이는 표현.

★ 정중도의 단계

같은 뜻이라도 조금씩 조금씩 존중도가 높아지는 표현이 있다. 경어로 갈수록 정중해진다.

교사의 관점 — "저는 다른 나라에서 강사로 있을 때도 그랬지만, '어떻게 말하면 자연스러울까'를 항상 생각합니다. 외국인이 한마디 하면 '아, 외국인이구나' 하게 되니까요."

복합동사 (複合動詞) ★

마스형 + 다른 동사를 붙여 하나의 동사처럼 쓰는 것.

형태 뜻 예
〜直す(なおす) 다시 ~하다 作り直す (다시 만들다) / やり直す (다시 하다)
〜かける ~하다 말다, ~하기 시작하다 食べかける

"「作り直してください」를 「もう一度作ってください」라고 해도 같은 의미지만, 하나의 동사로 말하는 것." "일본어와 한국어 사이에 차이가 나는 부분"이라 흥미롭다.

주방에 전달되는 표현 · 교체 요청

표현 상황
(주방에) 「〜が通っていません」류 주문이 주방에 안 들어갔다는 의미로 많이 쓴다
隣の席に行ってしまったのではないですか 옆자리로 (음식이) 잘못 간 거 아닐까요
チェンジしてください / 取り替えてください 바꿔 주세요

교사 주의 — "이렇게 말해야 한다는 건 아니고, 이렇게 말하기도 한다 정도예요."

함께 읽기 — 1~10번 문장

교사와 학생이 1번부터 10번까지 함께 낭독하고 문장을 바로 확인. 그중 나온 어휘:

표현 뜻
突然(とつぜん) 갑자기 — 「突然始まります」
一度に / 一気に 한꺼번에

3부 — 문장 바꾸기 연습 + そうです 두 종류 ★★

문형 연습 — 「〜のは〜です」

「私が〜したのは〜です」 형태로 문장을 바꾸는 연습. "바꾸는 것이 하나가 아닌 것도 있다" — 두 가지 이상 가능한 문항이 있음. "이것도 앞 단원의 복습이라고 생각해 주세요."

연습 문장에 등장한 소재 (전사 복원, 불확실):

예문 (추정) 뜻
〜さんが買ったのはワンピースです ~씨가 산 것은 원피스입니다
〜が好きなのは歴史です 좋아하는 것은 역사입니다
山本さんが買ったのはポルシェです 야마모토 씨가 산 것은 포르쉐입니다

시제 바꾸기 — 「食べます → 食べません / 食べました / 食べませんでした」

"이 동사는 과거로 바꾸면 돼요. 표현을 바꿔 주세요." 「食べる」 계열의 활용을 그 자리에서 확인 (동사 그룹 확인 포함 — 「入る」는 1그룹, 등).

★ そうです 두 종류 — 학생 질문에서 나온 핵심 포인트

학생 질문: "「かかるそうです」가 있는데 저는 이게 익숙해서요. 「かかりそうです」와 차이점이…"

형태 접속 의미 예
様態(양태) 마스형 어간 + そうです ~할 것 같다 (보고 판단) かかりそうです (걸릴 것 같습니다) / 雨が降りそうです
伝聞(전문) 동사 기본형·보통형(과거형도 가능) + そうです ~라고 한다 (들은 것) かかるそうです (걸린다고 합니다) / 雨が降るそうです

교사 답변 — "「かかるそうです」는 '(누구한테) 들었다'는 얘기잖아요. 「かかりそうです」는 '걸릴 것 같다'. 이 상황에서는 둘 다 괜찮아요." 즉 상황 자체는 둘 다 성립하지만 의미가 다르다.

たしか / たしかに — 번역 연습

「たしか」 = "아마, 분명" (기억을 더듬는 확신)

예문 (복원) 뜻
たしか、この辺りに薬局がありませんでしたか 분명 이 근처에 약국이 있지 않았나요?
たしか、山下さんのはずです 아마 야마시타 씨일 겁니다
彼は頭はいいが、あまり親切ではない 그는 머리는 좋은데 별로 친절하지 않다
たしか、まだ学生でしたよね 분명 아직 학생이었죠?

교사 정리 — "「たしか」에 붙이면 다른 의미가 된다는 부분을 확인하고 마치겠습니다." 학생들이 2번과 3번을 특히 헷갈려 함.

이 수업에서 남길 것

  1. 「しか」는 숫자가 있으면 "적다", 없으면 "그것뿐" — 이 하나로 구분한다
  2. 「だの」의 마이너스 뉘앙스 — 문장은 맞지만 직장에서 쓰면 이상하게 보일 수 있다. 이틀 연속 강조된 지점
  3. 음식점·카페 표현의 뼈대 — すみません / お待たせしました / 少々お待ちください / かしこまりました / 確認してまいります
  4. 손님 쪽 핵심 두 문장 — 「あとどれくらいかかりますか」(음식이 안 나올 때), 「注文したものと違うものが来たようです」(다른 게 나왔을 때)
  5. 복합동사 〜直す — 「作り直す」는 「もう一度作る」와 같지만 한 단어로 말하는 것이 자연스럽다
  6. ★ そうです 두 종류 — 마스형 + そう = 양태(~할 것 같다) / 기본형 + そう = 전문(~라고 한다)
  7. "어떻게 말하면 자연스러울까"가 이 단원 전체의 질문이다

전사가 불명확했던 항목

항목 상태
프린트 1~10번 표현 전체 복원 불가. 위 표는 맥락으로 재구성한 것 — 프린트 원본 필수 확인
번역 연습 1~10번 원문 대부분 복원 불가. 등장한 어휘(원피스, 역사, 포르쉐, 薬局, 山下さん 등)만 확인 가능
주방 관련 표현 원문 「〜が通っていません」류로 추정되나 전사가 심하게 뭉개짐
교재 포인트 번호 대응 「ポイント1」「ポイント3(5번)」「ポイント4」 정도만 식별
수업 도입부 (시력·안경 잡담) 수업 내용과 무관한 잡담
출석 호명 대부분 인식 불가
