1. 신부님의 기본 프레임 ★

핵심 내용
종교의 정의 관계적 상호존재에 대한 경건한 성찰 = "모든 것은 연결되어 있다" = 커뮤니언(communion)
바다와 파도 각자는 생로병사하는 파도, 그러나 파도가 곧 바다 → 싸울 일이 없다
산 오르기 깨달음 = 정상(오르막) → 깨달았으면 하산(내리막) → 남을 돕지 않을 수 없다 = 사회복지
성공회대 교육이념 열림 · 나눔 · 섬김 (커뮤니언에서 나옴)
종교 즉 사회복지 둘로 나눌 수 없다. 콘텐츠가 사회복지가 아닌 종교는 조심. 이해가 아니라 가슴에 사무쳐 사는 것

2. 역사란?

누가 정의
E. H. 카 현재와 과거 사이의 끊임없는 대화
후스토 곤잘레스 현재의 질문에 관해 과거가 말해 주는 매력적인 대화
로완 윌리엄스 (전 캔터베리 대주교, 웨일스 출신) 우리가 누구인지 이해하게 돕는 하나의 연결된 이야기. 목록 나열이 아니라 중요성 판단·배치. 과거는 "낯선 나라"이자 "우리의 어제"
정리 역사하기 = 과거 연구를 통해 현재를 해석하기 → 지금 종교 수탁 복지시설의 문제를 과거에서 찾는다

3. 1부 발제

발제 핵심
①② 오유진·이승원 역사 신학 고대 이스라엘(고아·과부·나그네) → 초대교회(사도행전 6장) → 루터(교육)·칼빈(병원·상하수도)·토마스 모어(유토피아) → 경건주의·프랑케 기관(무료학교·약국) → 19세기 선교(리빙스턴) → 베버리지(보편주의) → 한국: 광혜원(1885), 절제운동, 태화여자관, YMCA·YWCA
③ 문서준 근·현대 가톨릭 1784~1945. 질문: 근대적 사회복지냐 종교적 자선이냐 → 둘 다. 아동(양육→교육→자립), 의료(봉사→시약소→병원), 양로원(1885). 평가: "최초 ≠ 가장 큰 영향" — 재정·인력은 개신교보다 부족, 그래서 아동·노인 중심. 선구적이나 과대평가 금물
④ 김운해 한국불교 연기론적 관점, 복지 = 가장 좋은 포교. 조계종 시설 1995년 95개 → 2009년 958개(10배↑), 노인·아동 편중. 과제: 전문인력, 연구원, 불교복지재단
⑤ 조용익 원불교 시작점을 개교(1916)가 아니라 해방 후 전재동포구호사업·서울 보화원으로. 기준 3가지(사회복지 / 민간–공공 분담 / 종교지도자 인식 = 정산 송규 『건국론』)

4. 신부님 코멘트 ★★

주제 핵심
선교와 사회복지 선교 = 신자 만들기(좁은 전도)가 아니라 커뮤니언의 삶을 사는 것. 교회 = 그 삶을 증거하는 곳 → 사회복지기관 = 사회선교기관. "선교냐 복지냐?" → "선교를 어떻게 이해하나?"부터
초기 그리스도교 복지 천주교·개신교·성공회 모두 아동·의료·교육·여성 — 선교사들이 부족한 분야에서 시작
불교 시설이 적은 이유 외국 선교사 같은 확산 주체가 없었음. 지금은 빠르게 증가
용어만 다를 뿐 커뮤니언 = 연기, 선교 = 포교, 오르막·내리막 = 왕상·환상(정토진종) → 모든 종교가 같은 프레임
문자에 넘어지지 말 것 문자를 무시가 아니라 초월. 사회복지사 처우·이직률 문제도 이 마인드가 스며들어야
원불교 100년 넘어 4대 종교, 군종장교 TO. 창종 슬로건 정신 개벽 · 사람 개벽(오르막) → 사회 개벽(내리막)

5. 쉬는 시간 뒤 강의

  • 신앙(인생)은 반복 — 물러섬(관상) ↔ 나아감(행동), action in contemplation(칼 라너(?)). 세상은 새로운 게 없고 발견할 뿐
  • 복지국가 4단계: 이전(잔여적) → 형성 → 황금기 → 위기. 영국 NHS 대기 6개월·시골 병원/우체국 폐쇄, 미국 트럼프 = 복지국가 위기. ★ 한국은 황금기 없이 바로 위기
영국 사회복지 핵심 효시
엘리자베스 빈민법 (1601) 주체 종교 → 국가, 구빈세, 노동 능력자/무능력자 구분, 노동습관 교정 기초생활보장법의 효시 → 한국 생산적 복지·자활후견기관(지역자활센터) — 성공회 신학생들의 상계동 야학
자선조직협회 COS 성공회·자산가, 헨리 솔리(교재 "데니스"), 존 러스킨 재정, 런던. 난립한 자선 조정, 중복 방지 자원봉사센터(방문 실태조사), 공동모금회·사회복지협의회
인보관 운동 1872 화이트채플 사무엘 바넷 신부, 토인비 홀. 지식인·대학생이 빈민가에 함께 거주 상계동 성공회 나눔의 집 (녹취는 여기서 끊김)

6. 자료에만 있는 2부 내용 (녹취 없음)

  • 베버리지 보고서: 5대 악(궁핍·질병·무지·불결·나태), 보편주의, "요람에서 무덤까지"
  • 종교별 전달체계: 가톨릭 중앙총괄 / 불교 조계종 중심 / 개신교 교단별 분절 / 성공회 협의체형 사회선교
  • 서비스 모델: 의존 → 자립 → 상호의존
  • 영성 = 삶 전체를 관계 속에서 사는 방식 / 종교사회복지의 도전(자기 성장 몰입, 윤리강령과의 긴장, 비합리성 오해) / 宗敎 = 궁극적 가르침, religio = 다시 연결 / 표층종교 → 심층종교 / 종교와 사회복지의 "융합"
  • 사회복지는 종교의 부차적 업무가 아니라 본질적 역할 (규원 발제 논문과 같은 결론)

한 줄 결론

종교가 가슴에 사무치면 산에서 내려와 열리고 나누고 섬길 수밖에 없다 — 그것이 사회복지이고, 선교이고, 포교다. 종교마다 용어만 다를 뿐, 문자에 걸려 넘어지지 말 것.

이 문서는 마크다운 원본에서 자동 변환되었습니다.
