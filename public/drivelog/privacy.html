01수집하는 개인정보 항목 및 방법

회사는 서비스 제공을 위해 아래와 같이 최소한의 개인정보를 수집합니다.

구분 항목 수집 방법
계정 정보 이메일 주소, 표시 이름, Firebase UID, FCM 토큰 최초 가입 시 이용자 입력 / Google 로그인
운전자 정보 이름, 부서, 직급, 회사 코드(법인 모드) 이용자 직접 입력
차량 정보 차량 번호, 차종, 누적 주행거리 이용자 직접 입력
운행 기록 출발/도착 시각, 이동 거리, GPS 경로 좌표, 운행 목적(업무/출퇴근/기타), 메모 앱이 GPS 센서로 자동 수집
기기 정보 OS 버전, 앱 버전, 기기 식별자(설치 단위) 앱 실행 시 자동 수집
결제 정보 구독 상태, 청구 식별자 Google Play 결제 시스템을 통해 수신 (카드번호 등은 수집하지 않음)

02개인정보의 이용 목적

  • 법인차량 운행기록의 자동 측정·저장·관리
  • 국세청 양식 운행기록부(xlsx) 생성 및 공유
  • 법인 모드: 관리자 승인, 차량·운전자 동기화, 푸시 알림(FCM)

  • 고객 문의 응대 및 서비스 품질 개선
  • 법령 또는 약관 위반 행위 대응

03앱 권한 안내

앱은 다음 권한을 사용하며, 이용자는 운영체제 설정에서 권한을 언제든 허용/거부할 수 있습니다. 일부 권한 거부 시 핵심 기능(자동 거리 측정 등)이 제한될 수 있습니다.

권한 사용 목적 필수 여부
위치 (정확한 위치 · 백그라운드 포함) GPS 기반 운행 거리 자동 측정. 화면이 꺼진 상태에서도 안정적인 측정을 위해 백그라운드 위치 권한이 필요합니다. 필수 (운행 측정 시)
알림 운행 중 포그라운드 서비스 상태 표시, 관리자 승인 등 FCM 푸시 필수
인터넷 / 네트워크 상태 데이터 동기화, 푸시 수신, 클라우드 업로드 필수
배터리 최적화 예외 장시간 운행 시 시스템에 의한 앱 종료 방지 선택 (권장)
저장소 / 파일 공유 생성된 운행기록부 xlsx 파일 공유 선택
백그라운드 위치 수집 고지. 드라이브로그는 운행기록부 작성을 위해 앱이 백그라운드에 있을 때에도 위치 정보를 수집합니다. 위치 정보는 운행 측정이 활성화된 동안에만 사용되며, 광고·프로파일링 등 부수적인 목적에는 절대 사용되지 않습니다.

04Google API 사용 및 Drive 연동

드라이브로그는 이용자의 명시적 동의를 받은 경우에 한해 Google Drive API를 사용합니다.

  • 사용 범위(Scope): drive.file — 앱이 이용자 본인의 Drive에 직접 생성한 파일에만 접근합니다. 이용자의 다른 파일은 읽거나 수정할 수 없습니다.
  • 저장 위치: 운행기록 xlsx 파일은 이용자 본인의 Google Drive에만 저장되며, 회사 서버를 경유하지 않습니다.
  • 토큰 관리: OAuth 액세스 토큰/리프레시 토큰은 이용자 기기 내부의 보안 저장소에만 보관되며, 회사 서버로 전송·저장되지 않습니다.
  • 연동 해제: 이용자는 언제든 Google 계정 권한 설정에서 본 앱의 Drive 접근 권한을 철회할 수 있습니다.
드라이브로그의 Google 사용자 데이터 사용은 Google API Services User Data Policy(Limited Use 요구사항 포함)를 준수합니다. 회사는 Google 사용자 데이터를 광고 목적으로 사용하거나, 사람이 직접 읽거나, 제3자에게 판매하지 않습니다.

05개인정보의 보관 기간 및 파기

  • 운행 기록·차량·운전자 정보: 이용자가 직접 삭제하거나 회원 탈퇴 시까지 보관. 세무 증빙 활용을 고려해 이용자가 직접 보관 기간을 관리할 수 있습니다.
  • 계정 정보: 회원 탈퇴 시 지체 없이 파기. 단, 관계법령에 따라 일정 기간 보관이 필요한 정보(전자상거래법 등)는 해당 기간 동안 분리 보관됩니다.
  • 로그·접속 기록: 통신비밀보호법에 따라 3개월간 보관 후 파기.

파기 방법: 전자적 파일은 복구 불가능한 방식으로 영구 삭제하며, 출력물은 분쇄·소각합니다.

06개인정보의 제3자 제공

회사는 이용자의 개인정보를 원칙적으로 외부에 제공하지 않습니다. 다만, 다음의 경우는 예외로 합니다.

  • 이용자가 사전에 동의한 경우
  • 법령에 근거하거나 수사기관의 적법한 절차에 의한 요청이 있는 경우
  • 법인 모드에서 이용자가 회사 코드를 등록·승인한 경우, 해당 법인의 관리자에게 본인의 운전자 정보·차량·운행 기록이 공유됩니다.

07처리위탁

회사는 서비스 운영을 위해 다음과 같이 개인정보 처리를 위탁합니다.

수탁업체 위탁 업무 보관 위치
Google LLC (Firebase) 인증(Firebase Auth), 데이터베이스(Firestore), 푸시 알림(FCM), 크래시 리포트 해외(미국 등 Google 데이터센터)

08개인정보의 국외 이전

Firebase, Google Drive API 등의 이용을 위해 일부 개인정보가 미국 등 해외에 저장될 수 있습니다.

  • 이전 국가: 미국(주요) 외 Google 글로벌 데이터센터
  • 이전 항목: 본 방침 제1항에 명시된 항목 전반
  • 이전 방법: 네트워크를 통한 암호화(HTTPS/TLS) 전송
  • 보유 기간: 본 방침 제5항의 보유 기간과 동일
