드라이브로그 계정 및 데이터 삭제 안내

시행일: 2026년 5월 17일 · 최종 개정일: 2026년 5월 17일

탈퇴 방법

귀사의 관리자분에게 탈퇴 요청하시면 됩니다.

드라이브로그(DriveLog) 운전자 앱은 고객사(법인)가 운행기록을 관리하기 위해 도입하는 B2B 서비스입니다. 운전자 본인의 계정·운행기록에 대한 결정 권한은 소속 고객사에 있으므로, 탈퇴 및 데이터 삭제는 원칙적으로 소속 회사의 관리자에게 요청해 주십시오.

01회사 모드 사용자의 탈퇴 절차

  1. 소속 회사의 드라이브로그 관리자에게 탈퇴(승인 해제)를 요청합니다. (회사 내부 인사·총무 담당자가 관리자인 경우가 많습니다.)
  2. 관리자가 관리자 앱에서 해당 운전자의 승인을 해제하면, 운전자 앱은 더 이상 운행기록을 회사로 전송하지 않습니다.
  3. 운전자 본인이 단말에서 앱을 삭제하면, 단말 내 모든 차량· 운행기록·캐시가 즉시 파기됩니다.

02로컬 모드 사용자의 탈퇴 절차

회사 등록 없이 폰에만 운행기록을 저장하는 로컬 모드로 사용 중인 경우에는 별도의 탈퇴 절차가 없습니다. 앱을 삭제하시면 단말 내 모든 데이터가 즉시 파기되며, 로컬 모드에서는 애초에 회사 서버나 외부로 어떠한 데이터도 전송되지 않습니다.

03관리자에게 요청이 어려운 경우

퇴사·연락 두절 등으로 소속 회사 관리자에게 요청하기 어려운 사정이 있는 경우, 아래 이메일로 직접 요청하실 수 있습니다. 본인 확인을 거친 후 고객사와 협의하여 처리합니다.

요청처: LalaCatSoft 개인정보 보호책임자
이메일: deridokseo@gmail.com
요청 시 기재 사항:

  • 이름 및 연락처
  • 소속(또는 과거 소속) 회사명
  • 드라이브로그 앱에 등록했던 회사 코드(아는 경우)
  • 삭제를 원하는 데이터 범위 (전체 / 특정 기간)

04삭제되는 데이터와 남는 데이터

탈퇴(승인 해제 + 앱 삭제 또는 LalaCatSoft 요청 처리) 시 다음과 같이 처리됩니다.

대상 처리
단말 내 차량·운행기록·캐시 앱 삭제 즉시 영구 파기
LalaCatSoft Firestore 내 운영용 메타데이터
(이름, 부서, 기기 식별자, FCM 토큰, 승인 상태 등) 		승인 해제 시 비활성화, 고객사 요청 시 지체 없이 파기
중복 전송 방지용 임시 식별자(sentRecords) 전송 후 30일 경과 시 자동 파기
접속·통신 로그 「통신비밀보호법」에 따라 3개월 보관 후 파기
고객사 Google Drive 내 운행기록 본문
(암호화된 .enc 파일) 		고객사가 자체 보관·관리합니다. 「법인세법」 제60조에 따른 5년 보존 의무 등을 고려해 고객사 정책에 따라 보존·파기되며, 삭제는 고객사에 직접 요청하셔야 합니다.
운행기록 본문(고객사 Drive 내 파일)은 LalaCatSoft가 임의로 삭제할 수 없습니다. 운행기록 자체의 열람·정정·삭제는 정보 처리의 결정 주체인 소속 고객사에 요청해 주십시오.
